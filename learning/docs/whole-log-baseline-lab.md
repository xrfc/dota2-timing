# 本轮学习：从热门装备频率到阵容逻辑回归

对应L13–L15。工程协议见[固定实验](../../docs/whole-log-baseline-2026-10-21.md)。这份材料是学习任务，不是用户已完成的证明。

## 先会回答的五个问题

1. **X/y是什么？** X一行是一场主宰对局的双方英雄阵容，256列；y是一行11种装备整份有效日志是否记录。y可来自未来，X只能开局可知。
2. **不看阵容能做多好？** frequency对每装备返回train正例数/有效样本数。例：A杖815/1592≈0.5119，这个值用于每一场；不能改用验证196/398来拟合。
3. **逻辑回归学什么？** p=sigmoid(b+w·x)。正系数表示在其他编码固定的模型计算里增加该特征提高预测log-odds，不等于英雄导致购买或最佳出装理由。阵容维度相关且每侧固定5人，不能把系数当因果解释。
4. **C=1意味着什么？** sklearn的C是正则化强度倒数；小C更抑制大系数。固定C减少本轮比较自由度，并不证明C=1最优。分类概率模型不需要先定0.5阈值才能评估。
5. **为什么不只看准确率？** 对稀有装备全部猜不出也可能很准；Brier评价概率误差，AP评价正例排名，AUC评价两类排序。三者可能出现方向不同。

## 可独立完成的练习

### L13：手算频率与Brier

取y=[1,0,1,0]，固定p=0.5时Brier=0.25；若p=[0.9,0.1,0.6,0.4]，Brier=(0.01+0.01+0.16+0.16)/4=0.085。说明每一项对应什么。再从真实report复算一个装备频率值，验证它只用train。

### L14：读取一个逻辑回归模型

打开保存的logistic模型JSON，找到对应装备的截距与系数，按现有推理接口计算一个已保存阵容的概率，与预测载荷对照。不根据这个案例再改模型。说明为什么验证标签更改不应该改变模型文件里的拟合参数。

### L15：读懂对照表

逐装备写出train/validation Brier以及logistic-frequency差值；找出“训练改善但验证变差”的情况。解释：它提示泛化/校准问题，不等于证明阵容无信息。再找AP与Brier方向不一致的装备（如实际没有就写没有），解释排序与概率质量的区别。
