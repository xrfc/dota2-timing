## 2026-11-26：先保留语义，再拆模型代码

模型的已拟合状态、预测、拟合和流程是不同职责。M1先把状态和预测从脚本中独立出来，用固定旧源码与手造合成状态对照；没有训练出更好的模型。真实sklearn对象的手造属性只验证这一运行路径，不能声称已验证真实模型迁移。

版本身份也分生产者和消费者。兼容矩阵精确匹配完整组合和用途；同格式、能运行、在新补丁仍可信，分别需要不同证据。纯契约只能校验结构，后续读取器还必须核对实际字节；正常支持/仅复现/退役与验证状态分开。

预测只用DecisionInput与显式候选动作，ObservedOutcome在按比赛/英雄/时刻/domain匹配后才参与评价。这样未来结果和fold无法因传入整行样本而成为新特征。[M1说明](../../docs/action-model-m1.md)。
