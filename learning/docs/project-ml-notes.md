# 边做边学：项目里的机器学习（2026-10-30起）

## 2026-11-25：地图版本要按资产核验

地图底图更新只能证明显示图有新版，不能证明高度、通行区、树木或河道多边形同步更新。Gem 已提供部分 7.42 资产，现用地形来源仍为 7.41；因此“地图版本”需要拆成各资产的来源和补丁，而不能只写一个总版本号。

营地目录 v5 用 32 条记录保存两个补丁各 28 个营地。如果忽略 `patches` 条件全部读取，会把已经移动的营地同时算在新旧位置，污染距离特征与路线判断。先按补丁过滤、再核对身份和投影，才能谈模型跨版本验证。[核验证据](../../docs/patch-7.42-plan.md#2026-11-25-地图上游核验部分-742-资产已更新)

若录像提前结束，已经记录的后续受击能支持“估计到场时仍有受击”，但无法证明较晚的路线必然错过后续事件。
