# L16：排序改善，为什么概率误差反而更差？

配套[诊断协议与结果](../../docs/whole-log-calibration-2026-10-21.md)。本轮只读现有预测，不重训练、不做校准器拟合。工程诊断完成不自动表示用户完成L16。

## 先区分三个概念

- **区分能力**：把更可能发生的样本排到前面，AP/AUC关注这一点。
- **校准**：预测约70%的样本，长期是否约70%发生？观察固定概率箱内mean(p)与mean(y)，不是看模型所有样本平均是否一致就足够。
- **总体平均偏差**：mean(p)-mean(y)。它接近0也可能同时存在低概率段低估、高概率段高估，相互抵消。

示例：两模型概率[0.6,0.4]与[0.99,0.01]有相同排序；如果第一场实际0、第二场1，后者受到更大的Brier惩罚。这说明排序相同不保证概率质量相同，并非证明任何一个概率在统计上必错。

## 练习一：看固定10箱校准表

选择A杖或跳刀，写出每个非空箱的样本数、平均预测、实际正例率。注意小箱，不能把几场的偏差当作稳定校准规律。ECE10取决于分箱，不能因为换成别的箱更好看就改报告口径。

## 练习二：手算Brier分解

定义b=mean(p)-mean(y)，使用总体方差/协方差：

Brier = Var(p) + b² - 2Cov(p,y) + Var(y)

同一个验证集对比恒定频率q：

ΔBrier = Var(p) - 2Cov(p,y) + b² - (q-mean(y))²

预测变化只有与真实标签足够相关时才有收益；盲目拉大概率差异会增加误差。此式是精确数值恒等，不是因果解释，也不是常见分箱reliability/resolution分解。

选一个退化装备，核对报告四项相加是否等于已保存Brier差值；再选分身斧或金箍棒比较。不要把Var(p)本身当坏事，真正需要看它是否换来足够的标签相关性。

## 练习三：训练到验证发生了什么

比较两边正例率、平均预测、预测标准差、Brier和ECE；列出观测，再写可检验假设，不直接断言“就是过拟合”。若平均偏差很小但分箱误差明显，解释为何单纯统一调整截距未必解决。

## 练习四：少数错误与总体误差

top10指每个装备误差增量最大的10场；分母要用所有正增量总和才能解释它们占多少“变差贡献”，不要与带正负抵消的净总和混淆。真实比赛ID仅在本地报告查阅，不公开复制玩家信息。

## 后续研究边界

观察后可以提出更强正则化、校准或特征表达假设，但不能当场在同一验证集拟合校准器后声称独立效果改善。下一轮方案需明确拟合/选择使用哪些数据，并保留本轮证据。
