# B0：“被抓”可执行规则（2026-11-09）

状态：**第一版已实现（U131，2026-11-09）**，等用户抽查实例后冻结为B0任务契约。定义来自U115、U116（`docs/decisions/2026-11-07-b0-gank-definition.md`）；§5的问题用户已答（U131，`docs/decisions/2026-11-09-b0-gank-rules.md`）。阈值是助手建议、用户同意先这样跑，筛出实例后再调。

## 1. 一次“被抓”怎么认（流程）

对每个被评价的玩家（当前`positions=(1, 5)`，作为参数传入，U116）：

1. **起点**：敌方英雄对他造成第一次伤害或控制的时刻（战斗日志）。前面10秒内他没被敌方英雄打过，否则算同一次。
2. **窗口**：从起点往后20秒（U115暂定）。
3. **参与的敌人**：窗口内对他造成伤害或控制的敌方英雄；要求**≥2个**。
4. **结果**（U115选b）：
   - 窗口内死亡 → **被抓·死亡**；
   - 没死，但窗口内用了“保命手段”（§2） → **被抓·交出保命手段逃掉**；
   - 没死也没用 → 不算被抓（只是被打）。
5. **排除大团战**（§3.1）。
6. 另外两个条件**“从视野外出现”“离队友远”**（§3.2、§3.3）：U115说先四条一起筛。

## 2. 保命手段清单（从机制知识库推出）

一个技能或装备算保命手段，需要同时满足：**主动使用**（被动不算，有冷却或充能）、**作用在自己身上**（或队友对他用，见问题2）、机制属于下面A组（或用户勾选的B组）。施放时刻从战斗日志读，解析器v3的冷却可以核对“确实用掉了”。

| 组 | 机制（词表v15） | 知识库里的数量（接受的事实） | 例子 |
|---|---|---|---|
| A 核心 | 自身位移 | 技能71、装备15 | 闪烁匕首、原力法杖、回城卷轴、敌法师·闪烁 |
| A | 隐身 | 技能21、装备6 | 微光披风、影刃、暗影护符、诡计之雾 |

| A | 减益免疫 | 技能15、装备1 | 黑皇杖 |

## 3. 三个阈值

距离单位是游戏坐标（地图约16000×16000，一个塔的攻击距离约700）。

### 3.1 不在大团战（建议）

窗口内，以被抓者为中心1600范围内，**双方英雄合计≤6个**，且**我方（含被抓者）≤2个**。超过就记为团战，不算被抓。

### 3.2 从视野外出现（建议）

参与的敌方英雄里，**至少1个在起点前5秒内对我方完全不可见**（现有解析每秒有阵营可见性）。

### 3.3 离队友远（建议，按位置分别记）

起点时，离被抓者最近的我方英雄距离**≥1500**（1、5号位先用同一个值，按U116分位置记录，以后可分开调）。

## 4. 怎么校准

U115定的是先筛后查偏差。解析器v3跑完已采demo后：

1. 按上面规则跑一遍，统计每场被抓次数，以及每个条件各筛掉多少；
2. 随机抽20个“算被抓”、20个“差一点不算”的实例，给用户在录像里看是否符合直觉；
3. 有偏差再改阈值，改动和理由记决策。

## 5. 当时要用户确认的问题（已由U131回答）

## 6. 用户回答（U131）与实现

| 问题 | 用户回答 | 实现 |
|---|---|---|
| 1 保命手段 | A组都算；B组加速、弱驱散、幻象、林肯算，护盾/减伤不算 | `knowledge/awareness/save-means-v1.json`：166项（技能133、装备33） |
| 2 队友对他用的保命 | 算被抓，同时记“队友救下” | 结果分`self_save`、`ally_save`、`self_and_ally_save` |
| 3 阈值 | 先按§3建议 | `data.gank_events.PARAMS`，位置作为参数 |
| 4 新的一次 | 先按建议：前10秒没被打过 | `quiet_gap = 10` |

实现细节（助手选择，抽查时一起看）：

- **保命手段清单怎么生成**（`scripts/detect_ganks.py save-means`，从知识读取接口读事实v26）：技能排除被动和只能指向敌人的（游戏文件`behavior`、`target_team`）；加速技能只算U121的16个；装备的加速只算**主动效果**带加速的12件（相位鞋、疯狂面具、韧鼓、宽容之靴、微光、影刃、白银之锋、诡计之雾、炎阳纹章、散魂剑、克莱拉牧杖、迅疾闪光），只有被动移速的鞋子、动力鞋切换、散夜对剑等不算。
- **怎么认用了**：战斗日志里有施放记录；自己对自己、对队友或不选目标的施放才算，对敌人用的不算（如推推推敌人）；回城要在8秒内真的移动2000以上才算。
- **“被打”只看伤害**：起点和参与的敌人都按敌方英雄本体造成的伤害算；只有控制没有伤害的、召唤物和幻象造成的不算。
- **“从视野外出现”**：起点前5秒内，某个参与的敌人**有任意一秒**对我方不可见。
- **位置**：采集的OpenDota信息没有分路数据，按U8的规则在录像上推：1–10分钟大部分时间在本方优势路的两个英雄里，15分钟正补多的是1号位、少的是5号位，差不到25则不定。

## 7. 第一轮结果（162场，`reports/gank-episodes-2026-11-09/`）

- 候选（1、5号位被敌方英雄打到的每一段）18700段，算被抓1294次，平均每场每个1、5号位约2次；1号位757、5号位537。
- 结果：死亡953（74%）、自己保命逃掉324、队友救下6、自己加队友11。
- 只差一个条件就算的：离队友近1356、敌方只有1人790、属于大团战486、没死也没交保命304、敌人一直在视野里138。
- 自己保命里最常见的是相位鞋（166次）、敌法师闪烁、敌法师法术反制、幻影斧、主宰剑刃风暴。相位鞋很常在追人或打架时开，不一定是逃跑，需要抽查决定是否保留。
- 抽查清单：`reports/gank-episodes-2026-11-09/sample.json`（固定随机种子，20个算被抓、20个差一个条件）。
