## 1. 结论

1. **闪避要分两类**：敌方有“自身闪避”英雄时主宰金箍棒出现率29%，没有时19%（+9%，区间[+5%, +14%]）。“致盲敌人”类（沙王、修补匠、光法等）**没有**提高金箍棒（−3%，区间含0）。金箍棒针对的是闪避，不是致盲。
2. **否决坠饰↔可驱散保命**成立：14%对6%（+8%，[+4%, +11%]）；单英雄看，瘟疫法师在场时39%、神谕者20%。
3. **净魂之刃↔法力依赖**只在高置信子集（美杜莎、风暴之灵）成立：20%对7%。
4. **按“敌方有没有某特性”粗分时，斯嘉蒂之眼、碎颅锤、散夜对剑看不出效应**，但按单个英雄看有明显信号（见§3）。可能原因：特性定义太宽（如治疗类32人，几乎每局都有）、或这些装备主要由其他原因决定。需要你的经验判断。
5. **辅助样本太少**（巫医163、干扰者151、神谕者84局），所有配对区间都很宽，不能下结论（U17预期之内）。

## 2. 方法

- 9个维度由U23确定。来源：英雄登记表中的官方技能描述（127位英雄）。
- “依赖指向技能”用客观规则：基础技能（不含A杖/魔晶）中敌方单体指向主动技能≥2个，或大招为敌方单体指向（Valve原始枚举：behavior位8＝单位目标，位2＝被动；target_team 2/3/4＝敌方/双方/自定义）。57人。
- 其余8个维度：先用文字匹配找候选（命中太宽，如“法力”命中127人，只作提示），再由助手逐个人工标注，每条写**技能证据**和**置信度**（high/medium/low）。`dota_items.data.hero_traits.load_traits`校验每个英雄、技能名都在官方资料中，并禁止重复标注。手工标注共172条。
- 2026-10-31代码审查后收紧候选规则（只影响候选提示，v1标签与交叉检查结果不变，交叉检查只读标签）：文字不再包含Valve通用字段名（`AbilityManaCost`、`AbilityCharges`等，几乎每个技能都有）；`ward`/`charge`/`root`等加词边界，避免命中towards、forward、技能充能次数；“法力依赖”改为“文字提到mana，或基础技能最大蓝耗合计≥700”（蓝耗规则单独用分不开：莱恩950、暗影萨满1045未标，帕克475已标，所以只能两者取并集作提示）。候选人数变化：法力依赖127→50、召唤71（原89）、机动87（原96），其余不变；已标注英雄中只有朗戈“高机动”（灵呱一闪，low）落到候选外——该技能描述是给友方英雄加增益，本来就在§5抽查清单中，建议抽查时重点看。旧报告`reports/hero-traits-crosscheck-2026-10-31-v1`记录的是旧代码指纹，按规则不覆盖；以后重跑交叉检查须用新目录。
- 交叉检查：对每个英雄位置（主宰1号位；巫医/干扰者/神谕者5号位）、每个特性和子组、每件针对装，比较“敌方至少有1名该特性英雄”与“一个都没有”时的整局出现率；差值区间为正态近似95%区间。不考虑敌方装备和购买时间（这两点属于触发条件阶段）。

待你解释的点（可能指向漏标的特性或敌方装备触发）：

- 金箍棒对**噬魂鬼、露娜、司夜刺客**也很高，但它们没有闪避技能。猜测是敌方常出蝴蝶/辉耀，或有其他原因（如魔免、反伤）——需要你的判断。
- 散夜对剑对**军团指挥官（决斗）**和多个硬控英雄偏高，但“控制多”整体不显著——可能“控制多”的定义应改为“有关键单体硬控”，而不是“≥2个控制技能”。
- 碎颅锤对**风暴之灵、敌法师**高，符合“打断机动”；对巫妖、熊战士高原因不明。

## 4. 局限

- 标注依据当前官网技能描述快照，补丁未验证（`patch_verified=false`），驱散规则未逐条核对（“可驱散保命”整体low/medium）。
- 一局可能同时有多个特性的英雄，特性之间相关；这里只做单因素对比，不是因果。
- “出现率”是高分段行为频率，不等于“该出”。
- 只用训练集；验证集保留。
