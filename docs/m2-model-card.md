# M2 模型卡：出装时间预测（产品A v1）

| 项 | 内容 |
|---|---|
| 用途 | 赛前查看“我的英雄”关键装备在10/15/20/25/30分钟前做出的比例，作为高分段节奏参照 |
| 英雄 | 主宰1号位；巫医、干扰者、神谕者5号位（U9） |
| 装备 | U10、U11清单 |
| 主要输出 | 高分段平均比例（基线）。U13后页面不再接受阵容输入，修订2模型仅留档；页面为“高分段出装节奏参照” |
| 模型 | 修订2：敌方英雄one-hot（训练中≥30次的104个）＋阵营，逐格L2逻辑回归，C由训练集内分组5折CV选择 |
| 运行 | `reports/m2-item-timing-2026-10-30-r2/`（JSON系数，无pickle） |
| 数据 | M1快照：超凡+、≥30分钟、含主宰、2026-10-12至13、补丁7.41；训练1595场 |
| 评估 | M1验证集398场（非独立）；修订2为看过验证集后的第二次尝试；结果见`docs/m2-results.md` |
| 展示规则 | U13起页面只显示基线（`timing_view`以空阵容调用）；历史上曾按冻结规则显示模型格 |

## 不适用于

- 传奇段节奏或30分钟内结束的比赛；
- 判断“该不该出”某件装备（这是行为频率，不是装备好坏；如以太透镜，用户不常出不代表不好，U11）；
- 主宰对线崩盘局（已排除）；
- 未列出的英雄与装备。

## 已知问题

- 辅助样本少（神谕者84），区间宽；
- 阵容影响大多不可检出；
- 评估协议缺最小效果量门槛（待M4补）；
- 未做独立评估（M4）。

## 使用

```bash
PYTHONPATH=src .venv/bin/python scripts/coach_app.py --port 8780
```

打开`http://127.0.0.1:8780`。浏览器验收：`node scripts/acceptance/coach_app_browser.cjs NEWDIR`（需本机无头Chrome开启CDP 9229，见`reports/coach-app-acceptance-2026-10-30-v2/`）。
