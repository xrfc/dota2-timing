# 距离可信意识复盘模型还有什么缺口

2026-11-26。回答本轮用户的问题，作为现有计划的验收说明，不改变研究目标或批准训练。当前执行入口仍是[计划 §7](development-plan-2026-10-30.md#7-状态表唯一进度来源)。

目前有可审计的输入、历史局部死亡风险基线及行动比较原型，尚没有通过独立验收的行动推荐模型。不能用提取完成率、代码测试数量或一个历史分数，换算“可信度完成了百分之多少”。也没有足够依据承诺还需要几天。

## 先明确要信任什么

“未来 20 秒死亡概率是否校准”和“此刻转野比继续收线更好”是不同问题。历史死亡风险模型估计实际行为分布下的风险，不能直接把同一个概率当成每个替代行动的风险。分类实收核验说明实际收入可追溯，也不揭示没选的行动会赚多少。

可信不要求全知。模型可以利用部分可见信息作带不确定性的预测，但必须验证误差、覆盖与拒答，不能把缺失当空营、把相关关系当成行动因果。无需等所有地图细节都补齐才设计下一轮受限实验；真正必要的输入和允许保留的未知，应由具体任务契约说明。

若先完成当前局部问题——7.41f、一号位、固定兵线机会中的行动比较——剩余工作可归为三段：条件证据和任务契约收敛；同目标基线与单项改法的整场折外检验；新独立比赛的一次性验收及复盘试用。每段是否结束取决于证据，不能只按日程勾选。能分析任意版本、英雄和场景的复盘模型，还需逐场景扩展与跨版本检验，距离更远。

## 可验收的关口

| 关口 | 已有什么 | 通过还需要什么 |
|---|---|---|
| 事前信息和行动可行性 | 1,169 场、15,005 机会的收入与可见单位证据；时间、身份、来源与隐藏信息隔离经过核验 | 营地成员、整营可见性、实际路径、英雄清营能力分别有依据；缺项时保留条件或拒答 |
| 后果预测 | 30 秒分类实收主窗、20 秒对照的真实结果；结束截断和零收入分别保留 | 对已选行动分别报告收入、到场时间、风险的误差、覆盖和按比赛区间，优于同目标简单基线；未选行动保持未知 |
| 任务与标签契约 | 原 t..t+6 行为标签及五折固定，7,594 个未知动作保留 | 冻结待验证改法、评价指标、通过条件和拒答范围；改动作定义、收益权衡或样本范围须用户决定 |
| 局部风险有效性 | 有死亡风险历史基线，指标口径的错误已经识别 | 在一致的冻结口径下核验校准、每小时误报、提前量、目标死亡覆盖和分层误差；不能把旧平均精度当成行动排序准确率 |
| 新的独立验证 | 原开发集和旧验收使用历史有记录 | 原 337 场已正式评分，不能重称未触碰测试集；另行确认评估来源并授权，模型、指标和通过条件冻结后只评一次 |
| 实际复盘可用性 | 页面和证据展示已存在 | 分别检验事实准确性、盲评一致性、建议覆盖、拒答及端到端行为；不能靠全拒答获得表面准确 |

这张表是验收分解，不是新指标或新训练授权。Q7 仍要求每次真实训练和联网采集单独授权；具体研究改法应先成为可审查的方案。

## 当前这一轮为什么做营地条件

[金币主题 PR #47](https://github.com/xrfc/dota2-timing/pull/47)已完成 297 个差额格核验，金额未改写；一笔收入的分配机制仍未知。[营地证据 PR #49](https://github.com/xrfc/dota2-timing/pull/49)已完成全集 179,149 次可见单位观察。二者均未合并，不能把分支实现当成 main 已有能力。

当前紧接[营地条件核验](b5-camp-conditions.md)：分清存活与尸体、单位阵营与营地归属；检查静态地图支持的几何关系；用少量原开发录像验证生成器字段含义。出口是准确说明哪些条件可确认、哪些不可确认，不是强行把所有机会变成可刷营地。

补完这一步不需要追求完整游戏模拟器。若可确认覆盖不足，下一项应提出一个范围明确、能被现有证据检验的局部实验；只补该实验真正需要的证据，并由用户确认研究变更与训练，避免持续加字段却迟迟不检验模型效果。
