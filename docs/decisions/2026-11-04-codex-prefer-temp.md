# U84 Codex优先用临时账号

- 用户决定（原话）：“之前设置了一个codex账号，可以再设置一个吗，这个11.8就结束，设置一个有效期”；“登陆好了，优先调用这个账号的额度”。
- 落地：新一轮Codex调用`~/.local/bin/codex-prefer`，走临时账号（`CODEX_HOME=~/.codex-temp`）；到期后自动回主账号。这些都在本机，不进仓库。
- 有效期：到2026-11-08 20:51:42（北京时间）。这是该账号登录令牌里的订阅到期时刻，用户只说了11月8日。
- 助手的实现选择：额度用完不自动切主账号，批次会失败，告知用户后用`CODEX_ACCOUNT=main`重跑。
- 每批日志由`codex-prefer`写明账号。已完成轮次的`run_batch.sh`不改，它们记录的是当时实际用主账号跑的调用。
- 来源：用户消息。
