# U131–U135 路线B B0：“被抓”规则的保命手段、阈值、评价位置、留出集、抽查方式；分支规则（2026-11-09～10）

- 用户原话（2026-11-09），回答[B0规则](../b0-gank-rules.md)§5的四个问题：
  > 1abce都算
  > 2算，也是队友救下
  > 3先按你的建议
  > 4可以先按你的建议

## 决定

1. **保命手段**：A组（自身位移、隐身、无敌或吹风对己、减益免疫、免死、虚无对己、强驱散）都算；B组里a加速（U121的16个逃跑加速技能＋加速装备）、b弱驱散、c幻象、e林肯法球算；**d护盾/减伤不算**。
2. **队友对他用的保命**：算被抓（交出了保命手段），同时记为“队友救下”。
3. **三个阈值先按助手建议跑**：大团战＝被抓者1600范围内双方合计超过6个或我方超过2个；从视野外出现＝起点前5秒内至少1个参与的敌人对我方不可见；离队友远＝起点时最近队友≥1500（按位置分别记录）。筛出实例后再调。
4. **新的一次**：起点前10秒内没被敌方英雄打过。

## 实现中助手做的选择（不是用户决定，抽查时一起看）

- 装备的加速只算主动效果带加速的12件；只有被动移速的鞋子、动力鞋切换等不算（被动不会产生施放记录，动力鞋切换会，所以要排除）。
- 回城要真的传走（8秒内移动≥2000）才算；对敌人用的保命装备不算。
- 位置在录像上按U8的规则推（采集的OpenDota信息没有分路数据）。
- “被打”只看敌方英雄本体造成的伤害。

细节和第一轮结果见[B0规则](../b0-gank-rules.md)§6、§7。
