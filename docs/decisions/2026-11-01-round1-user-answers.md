# U33 交叉复核第1轮：用户对不确定项的回答

- 背景：Claude第1轮复核PR #11后，把116组不确定与U5抽查整理为`knowledge/mechanics/reviews/claude-round-001/user-questions.md`。
- 用户回答（2026-11-01原话摘录）与处理：
  1. 先天被动：“按理说都算被动，但是除了美杜莎魔法盾以外应该都可以破坏”。→ 97组先天被动改为“受破坏影响”接受；美杜莎·魔法盾排除。助手查到的Dota维基指引（经Steam讨论转述）称与另一技能绑定的被动如小小·长大、米波·分则能成一般不受破坏，与用户说法冲突，这2组保留不确定待用户核对。
  2. 关键被动：“可以查一下什么英雄比较怕破坏，一般潮汐猎人，小鹿（魅惑魔女），哈斯卡，钢背兽属于非常怕破坏的”。→ 区分两件事：被动**能否被破坏**（上条，事实层），与英雄**多怕破坏**（依赖被动的程度，推导层/规则层）。用户给出的4个英雄记为“非常怕破坏”，助手另起草候选名单待确认（见user-questions.md）。联网检索没有找到可靠的完整名单。
  3. 定义边界：
     - 3.1 “可以算，包括斧王反击螺旋也可以算”→ 固定值反击算反伤：半人马战行者·反伤、冥界亚龙·腐蚀皮肤、雷泽·风暴涌动改为接受；斧王·反击螺旋不在候选中，记为漏抽。
     - 3.2 “还有哪些是夺取控制？”→ 快照中夺取控制的有：魅惑魔女·魅惑、陈·神圣劝化、支配头盔、统御头盔、噬魂鬼·感染（可控制被附身的野怪）；是否算强制行为/召唤物待用户决定。
     - 3.3 “算，骷髅王骷髅兵也是不可控”→ 召唤物包括不可控单位：术士·邪术召唤改为接受。
     - 3.4 “算”→ 噬魂鬼·盛宴算吸血。
     - 3.5 “不算治疗，算免疫吧？”→ 神谕者·虚妄之诺排除于治疗；归属（免死/无敌/护盾减伤中的哪类）待定。
     - 3.6 “算”→ 昆卡·统帅朗姆酒（延迟伤害）算护盾/减伤。
  4. 游戏知识：
     - 4.1 “能主动释放或开关，但是不会触发指向性技能效果，比如不能触发敌法师的壳，莲花或者林肯”→ 编织者·连击、米拉娜·天界箭袋、凯·影武长刀算单体指向技能；不触发法术反制、清莲宝珠、林肯法球（user_reported，按U31单独记录，交Codex补到交互记录）。
     - 4.2 “不记得”→ 冥魂大帝·吸血灵魂A杖光环是否给吸血，保留不确定。
     - 4.3 “会”→ 熊灵缠绕之爪会定身，改为接受。
