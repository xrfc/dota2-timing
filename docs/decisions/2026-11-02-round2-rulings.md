# U40 Codex第2轮分歧裁定：先天被动、反伤、感应地雷、三组改判

- 背景：[待用户裁定汇总](../handoff/user-rulings-2026-11-02.md)A、B、C、E块，每块附助手建议。
- 用户决定（2026-11-02原话“A、B、C、E接收”，按当时列出的助手建议记录）：
  1. **A 先天被动（9组）全部排除**：“受破坏影响”只记录破坏后会暂时失效的战斗效果，规则、属性、物品、信息、经济类先天不记。涉及挽歌犹唱、预言、古龙诗集、驱邪护符、傻福、血魔法、基本法则锻造、贪魔的贪婪、职业猎人。这收窄了U33“除美杜莎魔法盾外都可破坏”的说法。这是记录口径，不证明这些先天在游戏中不受破坏影响。
  2. **B 反伤（2组）接受，附条件**：钢背兽·钢毛后背、潮汐猎人·锚击（仅海妖外壳净化触发）记为“受伤达到阈值后触发的范围伤害；攻击者不在范围内就打不到”。词表v3中“只被标记为反射伤害不算”的备注并非用户决定，下一版词表修改。
  3. **C 工程师·感应地雷不算隐身**：另记事实备注“地雷隐形，真视不可见，敌方进入生效范围时显形”。
  4. **E 三组接受**：玛尔斯·热血竞技场（位移他人）、玛西·回身踢（自身位移）、天涯墨客·戾影（召唤物）。
- 后续：贪魔的贪婪已由[U47](2026-11-03-break-rulings.md)改为接受。
- 范围：只裁定这15组。关键词扫描已接受的97组先天，未见A块那种纯经济、信息或给物品的同类，但这不是逐组复核。
