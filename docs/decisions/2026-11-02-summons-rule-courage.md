# U43 召唤物通用规则；勇气之霎改判算反伤；采用“克敌机先”

- 背景：[待用户裁定汇总](../handoff/user-rulings-2026-11-02.md)H块。
- 用户决定（2026-11-02原话）：“勇气之霎可以算反伤，克敌击先也可以用官方说法，H1H3给我列出来，召唤物规则可以接受，烈焰之军召唤物可被攻击，恶魔召唤也是召唤物而且可控”。
  1. **勇气之霎／反伤：接受，附条件**。反击打的是军团指挥官正在攻击的目标（U42），不一定是攻击者。这取代U42中“排除”的结果，事实描述不变。
  2. **机制中文名用官方说法“克敌机先”**。官方中文说明里就是这个写法（如`knowledge/hero-capabilities/hero-registry.json`），词表v3写的“克敌击先”不是官方用字。
  3. **召唤物通用规则采用助手建议：能被选中、控制或攻击的独立单位才算**。
  4. **克林克兹·烈焰之军：接受**，召唤物可被攻击。**谜团·恶魔召唤：接受**，是召唤物且可控。
- 证据性质：以上游戏事实是用户的游戏知识（`user_reported`），未运行游戏。
- 范围：规则是必要条件，不改变U33（不可控的召唤单位也算）、U35（夺取控制归入召唤物）、U39（毒蛇撕咬、闪光幽魂、唤魂不算）。其他召唤物组没有逐组按新规则复核，用户也没有逐组确认。
- 待词表下一版：改名“克敌机先”；写入召唤物规则；反伤定义加入“受到攻击触发、不一定打到攻击者”的情形（同U40钢毛后背、净化锚击）。
