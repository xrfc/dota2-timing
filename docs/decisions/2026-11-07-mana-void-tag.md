# U77 迅风斩莲花、死亡守卫；法力虚空标记疑似残留

- 用户决定（原话）：“莲花反弹迅风斩，目标也会进入迅风斩状态”“死亡守卫不算”“法力虚空算可被破坏，但是好像目前没有会被破坏的效果了，查一下以前版本的法力虚空是不是有被动效果可破坏？”。
- 核查：法力虚空的被动是Mana Thirst命石（敌人低蓝时加攻击力）。现有游戏文件里该命石标`Deprecated`，`thirst_enabled`为0，说明文字也没有被动，但`IsBreakable`仍是1。这是字段证据，不是游戏内实测。
- 影响：`IsBreakable`可能有旧版本残留，U48“直接用`IsBreakable`”要加例外。
- 待确认：法力虚空是否改为不算可被破坏；其他疑似残留的技能。
- 来源：用户消息。
