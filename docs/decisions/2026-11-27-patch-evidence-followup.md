# 7.42营地、目标复活与视野补证（2026-11-27）

用户要求：“按文档继续开发，优先补齐剩余营地类型、目标复活和完整视野证据，把需要我裁定的机制问题整理清楚，自己校验并同步维护文档。”

用户随后明确批准[定向采集方案](../patch742-evidence-collection-plan.md)：最多3场≥45分钟的精确7.42排位录像；平均段位至少70，先排除最终留出；最多6次下载尝试、20次元数据请求、4页发现请求、累计1.5GiB，录像年龄上限240小时。只作工程补证，不用于训练、总体行为估计或最终评估；预算耗尽仍无复活正样本则保留缺口。

营地语义采用当前官方说明与真实单位关联证据；历史补丁中的营地阶段/刷新规则仅作待核对依据，不自动继承。视野增加潜在来源、树状态与原始可见证据，缺当前有效视距、树空间映射或来源归因时保留未知。

本轮整理机制待决不代表用户同意建议；旧定义和已决事项先核实，不重复请求确认，也不把证据不足转成用户裁定。正式知识入口仍为7.41f；训练、留出、正式发布与PR合并未获新增授权。
