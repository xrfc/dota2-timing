# U191 取消人工评审，改由录像实际结果训练

2026-11-22，用户要求“不用人工评审，完全交给模型自训练”，并在助手给出的选项中确认：

| 问题 | 用户选择 |
|---|---|
| 好决策的标签来源 | 录像实际结果：用非留出demo里决策之后发生的事自动打标签（之后20秒是否死亡、补刀、金钱与经验得失、支援是否赶上等）。Codex只做交叉检查，不当标签。 |
| 真实训练授权（Q7） | 非留出开发集（U133，1341场）上可自行反复训练、调参，按比赛分组交叉验证；337场留出集只在最终版本上评估一次。 |
| 提交方式 | 执行的AI用自己的功能分支，可提交、推送分支、开PR；合并PR、推送main、删除分支仍须用户同意（U135）。 |
| 执行者 | Codex，模型 gpt-6.2-astra，推理强度 high（用户指定）。 |

## 影响

- 替代：U190“从一号位兵线盲评起步”中的人工盲评环节、2026-11-22本地评审（单人本机评审）的待判队列。已有评审工具和记录保留，不删除；人工判断不再是任何阶段的门禁。
- 不替代：留出集只评一次（U133）；联网采集新demo仍须单独授权；账号ID规则；项目只交付研究结论，不据此声称“玩家当时应该怎么做”的因果结论。
- 局限（助手说明）：录像结果反映高分段玩家实际做了什么、之后发生了什么，不等于“最优决策”；落选动作的后果只能用相似局面近似，存在选择偏差。
