# 7.42补丁：知识库维护方式（U177–U184，2026-11-19～20）

## 背景

官方2026-11-18发布7.42（`knowledge/mechanics/reviews/patch-update-2026-11-19/status.json`）。用户授权联网后，已抓新快照、官方补丁说明，跑完差异和影响范围（同目录`README.md`）：要复核2299/3295行事实；官方说明确认地图改动（双生之门、野点、中路塔位和河道、出兵点、夜魇泉水）。地图草稿的上游`leamare/dota-map-coordinates`最新仍是7.41。Codex也给过一份建议（先出《7.42影响清单》，地图单独核对），助手对照后采纳其清单格式和地图单列。

## 决定

- **U177**：机制事实从v27起改用**一个共享构建器**（输入＝上一版冻结事实＋本次复核文件），不再每版复制一个`mechanics_facts_vN.py`。旧的v2–v26模块和冻结数据原样保留用于复现，不删不改、不做生产者迁移。用户原话：“按这个建议做”。
- **U178**：7.42地图坐标走方案B——从7.42的demo反推门、塔、野点等实体坐标；上游`leamare/dota-map-coordinates`更新到7.42后改用上游，写入待办。**新版本demo的解析和处理暂时不做**（用户：“可以暂时先不做新版本的demo解析和处理”），所以7.42地图知识也随之暂缓。

- **U179**：复核分类按助手建议——第1类（只有天赋、命石变化）、第2类（纯数值）由AI处理，用户抽查第2类；第3类（说明文字）AI先审，机制含义变了才交用户；第4类（行为类数据）、第6类（未收录对象收不收）、第7类（全局机制）、第8类（证据冲突）、第9类（地图）由用户裁定；第5类里新机制的归类由用户裁定，删除的移入历史记录由AI处理。用户原话：“先按你的建议来”。
- **U180**：AI处理的部分由Codex `gpt-6.2-astra`辅助判断（用户：“AI处理建议让codex 6.2Astra进行辅助判断”）。两个AI都同意的记`two_ai`；两者不一致的交用户。

- **U181**（2026-11-20）：用户更正R09备注的说法——减益免疫和魔抗是两回事，只是黑皇杖和很多减益免疫来源同时提供魔抗。7.42的改动是“无视减益免疫的技能，伤害不再无视目标的魔抗”。
- **U182**（2026-11-20）：用户指出V社改动时常留下废弃内容。证据优先级：官方补丁说明＞游戏脚本＞数据接口的标记和数值＞数据接口的说明文字。7.42第8类四条按此解决（沙王·地震A杖删、戴泽·编织魔晶治疗删、死亡先知·巫术精研加速保留、帕格纳·生命汲取持续施法保留）。
- **U183**（2026-11-20）：巨魔战将·战斗专注按补丁说明删减速抗性、加状态抗性（用户：“减速抗性已经移除，新增了状态抗性”）。
- **U184**（2026-11-20）：删除一切命石相关内容，目前没有命石机制（用户原话）。数据接口里的命石文字一律不用；新技能抽取里只来自命石的机制不记。知识库现有行没有命石内容。

- **U185**（2026-11-20）：会改动知识库的结论再做一次双盲（用户：“可以开”）。全新的Claude子代理只看原文、字段和官方补丁说明，看不到Codex和Claude的结论；范围是117条“7.42下某对象有某机制”的判断（两个AI同意的改动、第4类改动、新机制、新技能抽取、分歧和冲突）。保留的1530行不送。材料`knowledge/mechanics/reviews/blind-742-001/`。
- **U186**（2026-11-20）：视野模拟先补视野来源、隐身状态、被砍的树（U154已列），再做“眼离悬崖边多远”和判错率的检验，偏高再考虑崖边细化高度（用户：“按你的建议做”“可以”）。另开分支做，不在7.42分支里。
- 地图：用户问Workshop Tools怎么导出，步骤见`docs/map-workshop-export.md`（用户自己操作，助手不碰客户端）。

- **U187**（2026-11-20）：死亡先知·吸魂巫术记伤害和治疗，不记吸血（用户：“算伤害和治疗”）。
- **U188**（2026-11-20）：变体精灵·变形A杖的复制体再放不算范围伤害（用户：“不算”）；不朽尸王·噬咬（魔晶）记自身位移（用户：“尸王魔晶确实有突进到目标旁边”）。
- 待用户：米波分摊伤害、米波·投掷视野（已解释，待回复）；凯·天隼冲击无视地形、巨魔战将·战斗专注减速抗性由用户进游戏核对（U183暂按删）。
- 被砍的树：用户同意改解析器（2026-11-20），但demo里没有直接的砍树记录，见视野分支`docs/map-knowledge-design.md`§10.6；视野工作在分支`claude/vision-sources-2026-11-20`。

- 7.41f的知识、地图、数据和模型继续作为当前可用版本，并标明补丁。
