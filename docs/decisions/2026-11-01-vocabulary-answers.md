# U28 机制词表定义（MK-T1）第一轮回答

- 背景：助手起草机制词表`knowledge/mechanics/vocabulary-v1.json`（42项）并提出5个问题（`docs/knowledge-framework.md`§5）。
- 用户回答与处理：
  1. **缺漏**：“目前没注意到缺少的”。词表维持，另按第4条新增`mana_gain`（共43项）。
  2. **闪避与致盲**：用户问致盲是什么效果——**待用户看完解释后再定**（助手倾向分开）。
  3. **受破坏影响**：“可以破坏的技能有特点的比如敌法师的法力损毁，潮汐猎人的外壳这类”。定义改为“英雄的**关键被动**会被破坏暂时失效”，不再以“整体失效/仅不能叠加”区分。助手核对：官方说明对法力损毁、海妖外壳都未注明破坏，海妖外壳的`behavior`也不含被动位，所以无法只靠官方字段判断；改为字段＋说明找候选、助手标“是否关键被动”、用户抽查（U5判断类）。
  4. **法力依赖**：“莱恩法力依赖低是因为3技能能够抽取其他单位的蓝量”。法力依赖改在推导层判断：高蓝耗**且**缺少自身回蓝手段；新增机制`mana_gain`（自身回蓝/吸蓝）。具体门槛在MK-T4/T5定。
  5. **减益免疫**：“减益免疫意味着只有无视减益免疫的效果才能产生作用，比如碎颅锤可以眩晕bkb效果单位”。按此改定义；并据此解码官方`immunity`枚举（0不涉及/1对友方生效/2对减益免疫友方不生效/3穿透：对减益免疫敌方仍生效/4不穿透/5对友穿透对敌不穿透），例子：狂战士之吼、淘汰之刃、魔爪、割裂→3，法力虚空、冰封禁制→4。`pierces_debuff_immunity`改为技能看`immunity=3`、装备看官方说明。含义仍待用户确认（`confirmed=false`）。
- 后果：`enums-v1.json`新增`immunity`解码；词表43项；推导层需新增“关键被动”人工标注与“法力依赖”组合规则。
