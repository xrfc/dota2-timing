# U50 回蓝倍率算自身回蓝；治疗增强不算治疗

- 背景：[待用户裁定汇总](../handoff/user-rulings-2026-11-02.md)J块第1题。
- 用户原话（2026-11-03）：“回蓝倍率算不算属性回蓝有什么区别？不都是能提高回蓝吗”；助手随后建议算，并询问治疗增强是否统一；用户答“治疗增强不算治疗”。
  1. **回蓝倍率算自身回蓝**：慧光、散慧对剑、陨星锤、慧夜对剑接受，注明“倍率，效果取决于已有回蓝”。用户没有逐字说“算”，这是助手按其反问和后续回答的理解，已向用户说明。
  2. **治疗增强不算治疗**：瘟疫法师·幽魂护罩排除。与U33一致。
- 范围：三元重戟已搁置（疑似退出）。U45光法魔晶保留治疗不变，它提升的是技能自身的治疗量；是否属于治疗增强由用户确认。其他现有治疗组没有逐组复查。
