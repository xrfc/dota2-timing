# U190 行动判断总架构与项目决策留档

2026-11-20。用户提出由项目模型综合各种可能原因评估决策，并确认“按你的建议做，另外我们所有的决策和调整都要写入文档，不要只存在对话记忆里”。

采用[行动判断总架构](../decision-framework.md)：先描述局面和可行行动，逐行动估计后果，再比较选择；从一号位兵线盲评起步，扩展到转野、换区与支援。现有死亡风险模型提供一项证据。用户确认架构和推进顺序；具体字段实现、标签、权重和训练安排继续分别记录状态。

全项目每次决定或调整都随工作写入仓库。用户决定在本目录登记来源、背景、采用方案及影响；实现调整在所属文档记录原口径、新口径、理由、证据、适用范围和待验证项，并同步计划与变更记录。新决定替代旧决定时双向注明。评审者的意见、助手建议和用户确认分别标明。
