# U39 复盘报告只做一份；“被抓”按敌方离线、多打少定义；只评价一个英雄（1号位或5号位）

- 背景：U38后待决Q13、Q15、Q16。
- 用户决定（2026-11-01）：
  1. **Q13：复盘报告做一份就够了。**产品C是一份赛后报告，A线的出装时间对照与B线的意识判断在同一份报告里，分区展示、证据各自标注。
  2. **Q15：“被抓”是一种局面，不是结果。**用户原话：“被抓应该是敌方有离开自己的分路、多打少等情况”。即：有敌方英雄离开自己的分路来到被评价英雄附近，形成局部多打少。死亡与否是这个局面的**结果**，另行记录，不作为“被抓”的定义本身。
  3. **Q16：只评价一个英雄**——用户本人操作的那一个，位置为1号位或5号位（优势路，沿用U4与U8的位置规则）。
- 助手对实现的理解（未经用户逐项确认，B0冻结前须确认）：
  - “离开自己的分路”：相对该敌方英雄在当前时段的所在分路/区域（例如按U8与OpenDota `lane`推断的分路，或前若干秒的常驻区域）发生移动；游走型4/5号位本身常不在线上，判定口径需单独确认。
  - “多打少”：被评价英雄周围半径R内，敌方英雄数大于我方英雄数（含自己）。
  - “等情况”说明定义不止这两条；其他候选（如敌方开雾后消失、多名敌方同时失踪）在B0中由用户补充或否定。
  - 结果另记：被评价英雄在窗口内死亡、被迫使用逃生技能或TP、安全脱离、反杀等。
  - 时间窗口与半径R尚未确定。
  - 训练样本：高分段比赛中同样只取1号位与5号位（优势路）的英雄作为被评价对象；用户本人的比赛只用于复盘试用（§8草案）。
- 判断一个局面是不是“被抓”可以用全知录像（这是标签）；评价“当时该不该察觉”只能用被评价英雄一方当时可见的信息（U6）。
- 来源：2026-11-01用户消息“复盘报告可以做一份就够了，被抓应该是敌方有离开自己的分路、多打少等情况，只评价一个英雄，1和5”。
