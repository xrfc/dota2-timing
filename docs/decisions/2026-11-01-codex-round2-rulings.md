# U37 Codex第2轮分歧的用户裁定

- 背景：Codex复核Claude第1轮P1（PR #13，`knowledge/mechanics/reviews/codex-round-002/`），19组与Claude不同：3组建议改接受，16组判不确定待用户裁定。Claude逐组给出建议后交用户。
- 决定（逐组见`knowledge/mechanics/reviews/user-decisions/U37.json`）：
  - **改接受6组**：玛尔斯·热血竞技场（位移他人）、玛西·回身踢（自身位移）、天涯墨客·戾影（召唤物）——Codex指出、用户同意；钢背兽·钢毛后背、潮汐猎人·锚击（外壳触发）算反伤；光之守卫·灵光算召唤物（鬼火能被点掉）。
  - **保持排除13组**：9个非战斗先天被动（挽歌犹唱、血魔法、古龙诗集、驱邪护符、基本法则锻造、贪魔的贪婪、预言、职业猎人、傻福）按不能破坏处理；炸弹人·感应地雷不算隐身；剧毒术士·毒蛇撕咬（本质是负面状态）、天穹守望者·闪光幽魂与琼英碧灵·唤魂（场地魔法）不算召唤物。
  - **新增1条**：玛西·回身踢多样施法带队友一起走，也算位移他人（友方）；抽取规则漏了这条候选。
- 由此确定的口径：召唤物须是能被攻击或摧毁的独立单位，附着的负面状态和场地魔法不算；受伤后触发、对周围造成伤害的反击算反伤；隐身只算真视可识破的；非战斗先天被动按不能破坏处理。
- 注意：“非战斗先天按不能破坏”是用户说“破不破坏不重要”后的项目口径，不是对游戏引擎的事实认定。
- 后果：当前结论汇总在`knowledge/mechanics/reviews/resolution-001/`（`scripts/resolve_mechanics_reviews.py`生成）。Claude第1轮、Codex第2轮原文件不改（Codex校验绑定了第1轮哈希）。下一版抽取器应把这9个先天加入不可破坏名单，并补上回身踢的友方位移候选。
- 回查：按新口径复查当前已接受的28组召唤物（熊灵、蛇棒、骷髅弓手、死亡守卫、佣兽、墓碑、支配类等），均为能被攻击的独立单位，没有需要改判的。
- 来源：2026-11-01用户消息“玛西·回身踢算自身位移也算友方位移，①的这些被动破不破坏不重要，可以算作不能破坏。剧毒术士·毒蛇撕咬不算，本质是个debuff，天穹守望者·闪光幽魂、琼英碧灵·唤魂是场地魔法，鬼火算，能被点掉。其他按你说的来”。
