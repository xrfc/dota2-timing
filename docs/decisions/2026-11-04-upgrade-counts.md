# U64 降低自身冷却算减冷却；提升治疗算治疗

- 后续：已被[U65](2026-11-04-round7-rulings.md)取代。
- 背景：助手询问A杖或魔晶降低技能自身冷却算不算减冷却，并提到它和U51相似。
- 用户决定（2026-11-04原话）：“哎可以都算，降低冷却算减冷却，提升治疗也都算治疗”。
  1. **降低冷却算减冷却**：含A杖或魔晶降低技能自身冷却。
  2. **提升治疗算治疗**：陈A杖、光法魔晶、主宰治疗守卫魔晶都接受。取代U51、U61的这一部分，也回到U45保留光法魔晶的结果。
- 后续：用户确认治疗增强仍不算（U65，见下）。
- U65（2026-11-04原话）：“提升治疗量才算治疗，治疗增强不算”。提升技能治疗量算治疗；放大受到恢复的治疗增强（如幽魂护罩）不算，U50不变。
