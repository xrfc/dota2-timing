# 一号位发育与支援的录像后果研究

U191 授权用录像里实际发生的结果训练。开发与留出按整场比赛隔离。实现选择均为本研究的工程与统计选择，非用户决定。[用户决定](decisions/2026-11-22-no-human-review.md)

## 1. 补刀前机会的全开发集复跑

开发集有 1,341 场已解析比赛。沿用 #33 的超凡及以上门槛，142 场未入选，余下 1,199 场满足补丁、模式、时长和基本输入条件。其中 76 场有原有逐秒小兵文件，1,123 场从本地压缩录像补抽。先前的结果只代表其中贡献样本的 73 场。完整的取样条件、固定五折、模型超参和评价指标见[研究协议](lane-study-protocol.md)，试点数字见[#33 研究结果](lane-study-results.md)。

建表时按原规则排除时钟回退的整场比赛，单列零机会比赛；保留动作未知、早期死亡和窗口截断的机会以核算覆盖。后果模型和时序模型使用同一批行动已识别、活过前六秒且结果窗完整的片段。行为模型可以使用动作已识别的早期死亡片段。

运行目录为 `reports/outcome-dev/`。逐场标识、折号、输入哈希和排除原因随 `manifest.json` 保存，三个阶段的 `summary.json`、`predictions.json` 和模型文件均留在本地。

### 五折结果与试点的差异

| 样本流转 | #33 试点 | 全开发集 |
|---|---:|---:|
| 检查输入的比赛 | 76 | 1,199 |
| 排除 / 零机会 / 产生机会的场次 | 3 / 0 / 73 | 24 / 6 / 1,169 |
| 全部机会 | 1,003 | 15,005 |
| 可识别动作（收线 / 后撤） | 706（571 / 135） | 10,724（8,723 / 2,001） |

| 符合后果条件 / 窗内死亡 | 701 / 34 | 10,652 / 506 |

4,281 段的动作仍然未知，占全部机会的 28.5%。前六秒死亡、窗口截断和动作未知可重合。全部 1,003 行试点记录逐行核对一致。排除原因逐类计数为 non-increasing extras-v1 clock（24 场）。

扩大样本后，末帧树的补刀误差低于同动作均值，死亡概率误差高于同动作均值。行为概率的逻辑回归仍优于固定频率；按 0.5 阈值，后撤召回率如上。两种网络按比赛配对，时序减末帧的补刀绝对误差差为 -0.02507 [-0.03078, -0.01891]（时序误差较低），死亡平方误差差为 +0.00040 [+0.00024, +0.00056]（末帧误差较低）。方括号为整场重抽样的 95% 区间。这些指标评估实际动作的后果。[逐模型指标、校准、配对区间和文件指纹](acceptance/outcome-full-lane.json)
