# 一号位补刀前的离线学习实验

本实验依次检验三个问题。已识别的留线和后撤，各自随后有多少线上补刀及死亡风险？在决策当时，这个样本群体较常做哪种动作？加入决策前十秒的可见历史后，同一批片段的预测误差有无下降？用户确认了这条开发顺序，允许在独立 worktree 开发。具体特征、模型、超参数及误差比较是本次实现选择。

## 对局、动作和结果

- 使用本地开发集。按回执验证平均段位 `avg_rank_tier >= 70`（超凡及以上），按元数据要求天梯全英雄选择、时长至少 900 秒、补丁 ID 60，开始时间在北京时间 2026-09-15 15:00 至 2026-11-18 16:00 的左闭右开区间。仅纳入数据入口核实输入完整的场次。平均段位说明整场水平，每名一号位的个人段位仍未知。既有独立留出比赛继续排除。
- 从第 900 秒起，按现有兵线前沿、英雄位置及可见敌方小兵识别补刀前机会，同一英雄两个机会至少相隔 120 秒。保留决策时点、该时点的己方视角特征、动作识别和后果窗口。动作识别使用随后六秒的成功线上补刀和相对兵线的位移。补刀后又明显撤退、位置缺失或证据不足等情形可归为未知。一个玩家留在原地却漏刀，可能无法被识别为留线。
- 行为参照使用动作可识别且六秒观察完整的片段。后果评估还要求活过前六秒，且能观察至第二十秒。预测目标分别为第 7 至 20 秒的线上补刀数和该窗口内是否死亡。各排除数及每折覆盖随产物保存。只对已识别的历史动作预测后果；这些概率不能单独证明某次后撤会救下玩家。补刀数只覆盖一类资源收益。
- 每场比赛仅分到一个开发折。`SHA256("lane-study-v1:" + 十进制比赛编号)` 按大端整数取模 5 固定分配。每折用其余四折训练。三阶段沿用同一份样本清单。比较后果模型时逐片段配对，对训练折未见的动作另计缺乏支持的数量。

## 模型和输入

静态特征取决策秒的对局时间、距己方兵线前沿距离、附近可见敌方兵数、生命比例、法力、就绪保命手段数量，以及最近受到英雄伤害的标记。时间帧取决策前十秒、前五秒和决策秒。每帧读取可见存活敌人数、最近可见敌人距离、最近队友距离、未见或至少十秒未见的存活敌人数、自身二维位置（两个通道）以及该帧自身位置到己方兵线前沿的距离，共七个时序通道。历史帧允许缺失，隐藏敌人真实位置、未来移动和事件均不得进入这些特征。

| 阶段 | 对照和预测模型 | 学习设置 |
|---|---|---|
| 监督后果 | 训练折内同动作的实际均值，以及使用静态特征、末帧、观察到的动作的直方图梯度提升树 | 补刀回归与死亡分类分别拟合提升树模型，最多 100 轮，学习率 0.1，最多 15 个叶结点，每叶最少 20 个片段，关闭早停；去掉训练折全缺失的列。训练折死亡标签单一时用该折死亡率。 |
| 行为参照 | 训练折整体留线频率，以及逻辑回归估计可识别动作中留线的概率 | 只使用静态特征和末帧。训练折内中位数填补、增加缺失指示、标准化。L2 正则，C=1，最多 1,000 次迭代。单一动作折使用训练频率。 |
| 时序挑战 | 全三帧树、仅末帧神经网络、三帧时序卷积网络 | 两种网络共用结构和参数数量。8 个宽度为 2 的共享 tanh 卷积核读取相邻帧，左端补零，时间平均池化后拼接静态特征及动作，联合拟合补刀和死亡两个输出。三帧树沿用末帧树超参数。 |

神经网络使用训练折中位数居中、标准差缩放、缺失指示及 ±10 截断。序列通道在训练折的所用时点共享缩放。补刀输出在训练折标准化后优化平方误差，死亡输出优化二元交叉熵；核权重和输出权重 L2 系数 0.01，SciPy L-BFGS-B 最多 100 步。回归结果还原为非负补刀数；死亡标签全相同时返回该折观测率。三个阶段固定基础种子 20261122，每折种子为基础种子加折号。推断测试中的结果字段不参与任何模型输入。

## 指标和证据强度

- 后果模型输出补刀 MAE、死亡 Brier 分数、平均精度、五档校准及风险阈值 0.5 的误报数除以该组实际有片段的场次。行为模型输出对数损失及两动作各自的召回率。各组同时报告样本数；某组仅有一种死亡标签时平均精度留空。最近未受英雄伤害的子组用于检验模型能否更早看出风险。
- 逐片段汇总会给机会较多的比赛更大权重。模型差异另按整场配对。对共同片段计算模型 A 减模型 B 的绝对补刀误差、死亡平方误差，在每场内取平均，再对比赛等权平均。使用固定种子 20261122 对整场有放回抽样 2,000 次，报告 2.5% 与 97.5% 分位区间。负值代表模型 A 误差较小，跨零时报告差异未区分。比较时同时阅读各折场数、死亡数与两动作覆盖。
- 神经网络分别与单帧神经网络、三帧树及末帧树比较。三帧树与末帧树之差帮助区分历史信息贡献。行为频率展示人群习惯。开发折上的预测差异只支持对这批观察数据的结论，跨补丁效果、落选动作的后果和玩家决策质量仍需其他证据。

## 复现与产物

在已获准使用该批开发场次的 WSL 环境中，从本实验代码所在仓库根目录运行以下命令。`SOURCE` 指向保存既有回放与虚拟环境的本地项目目录，`RUN` 用一个新的实验目录。数据准备的筛选参数与行为以当前版本的 `--help` 和清单为准。

```bash
SOURCE=/home/node/.openclaw/workspace/work/dota2-timing
PY="$SOURCE/.venv/bin/python"
RUN=reports/lane-study-reproduction
export PYTHONPATH="$PWD/src:$PWD:$PWD/scripts"
"$PY" scripts/lane_study_data.py --help
"$PY" scripts/lane_study_data.py --root "$SOURCE/data/demos-2026-11" \
  --map-dir "$SOURCE/data/map-reference-2026-10-26-v1/coordinates/data" --out "$RUN"
"$PY" -m scripts.lane_study baseline --root "$RUN"
"$PY" -m scripts.lane_study behavior --root "$RUN"
"$PY" -m scripts.lane_study sequence --root "$RUN"
```

`manifest.json` 与 `rows.jsonl` 分别记录队列、划分和样本。每阶段子目录内的 `predictions.json` 保存逐片段折外预测，`summary.json` 保存分组指标、输入摘要、代码和依赖版本信息及模型文件指纹。比较前先核对输入指纹。各折 joblib 产物用于复算该折测试场次，落盘后重载并重算预测。完整产物留在本地，阅读实验结果时同时记录所用清单、样本覆盖和版本。
