# M2 结果：出装时间预测（按冻结协议，2026-10-30）

运行：`reports/m2-item-timing-2026-10-30-v1/`（`model.json`系数、`results.json`指标、`manifest.json`指纹）。授权：U11。协议：`docs/m2-design.md`，训练前冻结，结果出来后**未改动、未调参重跑**。

```bash
PYTHONPATH=src .venv/bin/python scripts/train_item_timing.py --snapshot reports/m1-match-table-2026-10-30-v1 --output NEWDIR
```

## 1. 结论

**阵容逻辑回归整体不优于基线（不看阵容的高分段平均概率）。**

- 130个(英雄,装备,分钟)组合中80个满足建模条件；其中63个模型Brier比基线差，25个“更差”的区间完全在0以下。
- 按展示规则，只有神谕者3项（以太透镜20/25分钟、绿杖25分钟）显示模型。但神谕者验证集只有15人，35项检验里出现3项“通过”接近偶然水平（多重比较），**助手建议这3项也按基线显示**（见§4，需用户决定）。
- 各英雄宏平均Brier（越低越好）：主宰 基线0.0960／模型0.1057；巫医 0.1500／0.1719；干扰者 0.1354／0.1490；神谕者 0.0833／0.0899。

## 2. 为什么会这样（诊断，不改变结论）

- **过拟合**：输入是约250个英雄one-hot（友方+敌方），而例如巫医训练只有约160人。每个英雄在训练里只出现几次，模型把偶然的共现当成规律；C=1.0的L2正则对这么稀疏的数据太弱。
- **信号本来就弱**：高分段主宰几乎固定“狂战斧→夜叉→分身”，阵容最多让时间前后浮动1–2分钟，而5分钟一档的标签分辨不出这种差异。
- **验证集小**：辅助英雄验证样本15–44人，区间很宽。
- 这正是协议预先写明“可能且可接受”的结果。

## 5. 不能得出的结论

- 不能说“阵容不影响出装”：只能说这个模型、这些数据看不出可靠影响。
- 不能把基线表当传奇段节奏（U7有意以高分段为标准），也不代表短局。
- 这不是独立评估（M1数据卡§5）。

## 6. 修订2结果（U12，看过验证集后的第二次尝试）

运行：`reports/m2-item-timing-2026-10-30-r2/`（`--revision 2`）。只用敌方英雄（训练中≥30次的104个，其余并入“其他”），每格在训练集内分组5折CV选C。

- 交叉验证选中的C：0.001×35、0.01×6、0.03×17、0.1×17、0.3×3、1.0×2——**多数选了最强正则**，即模型几乎退回基线。这是CV在告诉我们：这些格子里阵容信号小于噪声。
- 宏平均Brier（基线／修订2／修订1）：主宰 0.0960／**0.0955**／0.1057；巫医 0.1500／0.1504／0.1719；干扰者 0.1354／0.1358／0.1490；神谕者 0.0833／0.0837／0.0899。过拟合消除，但整体仍与基线持平。
- 80个建模格：28个略差；区间完全<0仅1个（修订1为25个）；区间完全>0共5个。
- 按展示规则显示模型的5格中，4格改善量≈0（≤0.0002，模型概率与基线几乎相同），实际显示效果等同基线；**唯一有实质改善的是主宰“30分钟前蝴蝶”**：Δ=0.0111，区间[0.0010, 0.0216]。
  - 系数（C=0.1）：敌方有天怒法师、风行者、裂魂人、斧王、军团指挥官时蝴蝶更晚；有虚空假面、黑暗贤者、圣堂刺客、斯温、敌法师时更早。与常识一致（面对魔法爆发/控制先出BKB等，面对物理核心更早出闪避），但这是第二次尝试中的单格结果，须M4复核。
- 神谕者修订1的3项按U12显示基线。

结论：产品A v1以高分段基线节奏表为主，主宰蝴蝶附带阵容调整（标注“初步”）。展示规则缺少“最小效果量”门槛，导致≈0的改善也被判为通过——记入待办，M4协议补上。
