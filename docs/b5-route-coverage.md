# B5 收线／转野的开发覆盖盘点

2026-11-25，按[用户本次决定](decisions/2026-11-25-route-focus.md)推进[计划第③步](development-plan-2026-10-30.md#b5-决策自评与迭代)。本轮先确认两个动作是否有开发数据支持，不训练、不输出收益优劣。

## 研究口径与证据身份

用户已定：一号位、收线／明确离线朝野区移动、从决策秒起 30 秒主窗及 20 秒对照。未来轨迹只用于识别实际动作；营地为空或途中死亡不取消已经识别的转野。未观察到明确动作保留未知。

- U191 开发范围为 1,341 场；其中既有兵线机会表有 1,169 场、15,005 个机会。保持原采样、比赛级五折和机会全集，旧动作未知、早死、结果窗不完整均保留。
- 原 337 场已于 2026-11-22 正式评分；本轮用原划分函数拒绝留出比赛，不读取其状态。新独立验收来源待确认。
- 三场已读录像仅作回归：26 个兵线候选，11 收线、1 明确转野、14 未知；104 项分类金额对平。这些是历史回归结果，不是新模型的独立评价。
- 旧 B5 评分：2,594 个占优主张全部未过平衡门槛。原模型现金差含购买等收支，不能与新实收目标直接比较误差。

证据来自已登记的固定版本：[U191 与历史评分](https://github.com/xrfc/dota2-timing/blob/7ca2ae3d14edae67042634f820a9456827d78ce1/docs/outcome-autotrain.md)、[评分器与基线](https://github.com/xrfc/dota2-timing/blob/5cc726716229dec72725effa22584907d20fdda3/docs/b5-decision-scoring.md)、[三场走位与金币回归](https://github.com/xrfc/dota2-timing/blob/a392ff0e638441c6681e2ca4b88e391c39057f9b/docs/b5-farm-gold.md)。这些依赖尚在各自主题分支，本轮从 main 开发独立盘点工具，不把工作台提交合进本 PR。

## 实现和复算

```bash
PYTHONPATH=src PYTHONDONTWRITEBYTECODE=1 .venv/bin/python scripts/inventory_b5_routes.py \
  --workers 4 --out reports/b5-route-coverage-20261125
```

输出目录必须不存在，避免覆盖旧产物。固定 `reports/outcome-labels/rows.jsonl` 的 SHA-256 为 `f2f1254c33158b6923fa7185dd1454414fc8483baaa7c8f69d5cf88d6eb395ca`。先校验机会身份、重复与比赛折，再按比赛读取 `data/demos-2026-11/state-v3/<match>.jsonl.gz`。使用公共 `data.source_io`，记录输入压缩文件、地图和实现指纹。缺失状态仍保留机会，身份错、重复时刻、坐标体系不符则报错。`summary.json` 保存分母、缺失、分组和来源清单；`rows.json` 保存逐机会标签与事前字段可用性，均留在本机。

动作阈值沿用 11 月 24 日工程选择，没有在本轮调参：固定决策秒最近己方兵线前沿，前三至六秒离兵线增距至少 350、终点离前沿至少 850，向某营地接近至少 450、终点距营地至多 1200、至少三次逐秒靠近，判为转野。未识别明确离线且七个位置至少四个在前沿 800 内、末点在内、净增距至多 150，判为收线。缺起点或前沿、承诺动作前缺秒／死亡、单秒跳位超过 700、其余几何不明分别计数。跳位不自动解释为步行或传送。已识别的离线不会因后续轨迹中断而撤销。

事前字段白名单：本人位置、本人移速、己方兵线前沿、静态营地几何。分组采用英雄、游戏时间十分钟段及本人生命比例是否低于 50%；这些只是助手选择的描述性切片，不是新训练划分、相似局势判定或已确认的模型阈值。汇总同时报片段数和独立比赛数，同一比赛可支持多个动作。两种动作都出现只意味着最弱的样本存在性，不代表平衡或支持充分。

## 可用信息的边界

营地位置使用现有 7.41 地图，其来源登记为尚未经过本地录像全面认证。靠近营地可能只是路过，标签不是人工真值。静态坐标不证明营地有野、玩家看得到野或路线可通行。当前状态字段不能直接核实事前营地可见存量、实际可通行路线及清营耗时；本次不把全知状态的敌方、野怪实况投射为事前特征。

`state_reaches_20s/30s` 只检查状态文件尾时刻达到窗口端点，不证明金币端点完整。分类累计金币仍需已登记的原始录像抽取及对账；不能拿现金余额代替。原 1,341 场中未出现在机会表的 172 场，原因本次不重建，不能记为“没有转野”。

## 本轮结果与下一项

开发覆盖已完成，所有 1,169 场状态文件均可读，15,005 个机会均保留。固定动作规则得到：

| 动作 | 片段数 | 占全部机会 | 独立比赛数 |
|---|---:|---:|---:|
| 继续收线 | 6,235 | 41.55% | 1,157 |
| 明确离线朝野区移动 | 1,176 | 7.84% | 708 |
| 去向不清 | 7,594 | 50.61% | 1,158 |

未知原因：5,963 段几何证据不满足任一动作；1,350 段在明确动作前跳位；281 段在明确动作前中断。这些都是规则结果，不能把未知解释为错误决策，也不能直接放宽阈值。三场已审查录像 26/26 标签与原实现一致。

共 73 个英雄，其中 59 个出现两种动作。按英雄×十分钟段×血量分组共 522 格，199 格同时出现两种动作；这个计数不代表局势充分可比。五折各有 213～255 个转野片段，来自 136～151 场。详细分布和逐文件指纹保存在本机报告，摘要见[验收收据](acceptance/b5-route-coverage.json)。

旧标签到转野：418 段原为 farm、507 段原为 retreat、251 段原为 unknown；原 retreat 另有 1,494 段仍为未知。后撤不能替代转野，按旧 eligible 子集筛选会丢掉新可识别动作。

本人位置、移速、己方前沿和静态营地几何四项均可读取，状态文件均延伸到两个窗口端点。原始 demo 文件 1,169/1,169 存在（仅检查存在性，未重新解析或核验全量金币）。事前营地可见存量、可通行路线和清营耗时仍缺核验，分类金币尚未批量抽取；有坐标不等于信息充分。

结论：全局存在足够多的转野实例，值得继续验证；不能据此认定每个英雄／局势都有足够支持。第③步保持未完成，下一项是按未知原因核查标签可信度，并在同一机会全集建立真实金币和事前营地条件的可核验读取入口。保留原判定阈值和所有机会；任何重新定义动作或收益的方案先登记并确认。

下一实验先登记假设、同目标中位数／简单回归等基线、改善幅度及允许退化，再按整场折外比较；支持不足时保留条件建议。平衡阈值不因覆盖少而放松，跨场景收益权重和新独立验收来源仍待用户确认。

本轮代码专项覆盖留出拒绝、输入指纹、重复时刻、未来／敌方字段隔离、动作承诺后中断、缺失状态保留及独立比赛计数。全量验收结果见本机 `reports/b5-route-coverage-20261125/check-full.log`，执行前后项目文件指纹包含未跟踪源码。

## 未知动作诊断

```bash
PYTHONPATH=src PYTHONDONTWRITEBYTECODE=1 .venv/bin/python scripts/audit_b5_route_labels.py \
  --out reports/b5-route-diagnostics-20261125
```

先校验本页验收收据登记的覆盖报告、全部机会和生产者指纹，再校验每场压缩状态的原指纹。重放全部 15,005 个标签及基础字段，任何漂移即失败。仅对原未知输出诊断，不重新分类；原文件和报告不修改，输出目录必须不存在。压缩状态中的紧凑和带空格 JSON 均可按秒筛读，未选时刻仍检查递增顺序。

中断细分为缺帧、缺英雄、缺生命状态、非存活状态、缺坐标。跳位保留首个超过 700 的位移及前后移速，不推断它是传送或某个技能。几何未达条件时列出收线的具体失败条件，并在所有营地、第三至六秒中列出转野条件失败最少的一组；并列按秒和营地编号选取。这个“最少失败数”仅供定位规则，不代表置信度、最合适营地或建议。

诊断读取的后续本人位置、生命状态和移速只用于事后核查，不进入事前特征。没有用金币、后续击杀或敌方全知状态来判断动作。代码专项覆盖输入漂移、原已知标签变更、缺帧与非存活区分及 JSON 两种格式。

### 诊断结果（2026-11-25）

全部 15,005 个标签及基础字段重放一致；7,594 个未知逐条解释，未改变任何标签。[诊断收据](acceptance/b5-route-diagnostics.json)

| 原未知原因 | 本轮核实 | 片段数 |
|---|---|---:|
| 中断 | 全部是前六秒明确动作前出现非存活状态；没有缺帧、缺英雄或缺坐标 | 281 |
| 跳位 | 首个跳位为 700–1,200／1,200–3,000／超过 3,000 单位 | 685／602／63 |
| 几何未达条件 | 收线和转野均未满足现有规则 | 5,963 |

几何未知中，1,342 段仅因相对固定前沿增距超过 150 而未判为收线，其余两个收线条件均成立；这提示检查固定前沿随兵线移动的适用性，不能直接认定原标签错误。另有 3,111 段在全部营地和第三至六秒中，至少有一组仅差一个转野条件：2,901 段差“距营地至多 1,200”，93 段差“离线增距至少 350”，61 段差“向营地接近至少 450”，46 段差“距兵线至少 850”，10 段差“至少三次靠近”。这些是既有规则的边界诊断，不能把它们直接改标为转野，也不代表已经到达／清营。

下一核验应优先检查固定前沿及六秒内靠近营地终点门槛，结合实际轨迹验证它们是否误读意图；如需改变定义或阈值，先提交具体证据与方案。真实分类金币仍需基于原始 demo 建立冻结开发机会的批量入口；营地可见存量仍待核验。第③步保持未完成。
