# 路线 B · 一号位行动判断总架构

U191 以录像后果提供自动标签。收线与后撤的行动比较已按整场交叉验证，在具备双动作重叠的相似局面估计两套后果。未观测动作的估计和实际动作的误差分别报告。[行动价值研究](outcome-autotrain.md)

2026-11-20 采用此路线（[U190](decisions/2026-11-20-decision-framework.md)）。首个问题是兵线处多留几秒还是立即后撤，后续把转野、换区、支援放回同一次行动比较。

## 从录像到判断

1. 固定补丁、比赛、英雄、决策秒与己方视角。每条依据保留观察时刻和来源，注明可见事实、推断或未知。敌方真实位置及未来动作只进事后核验。
2. 枚举可执行动作，写明目的地、耗时、前提及排除理由。例如“再补两刀后往塔撤”和“立即沿塔侧撤”有不同的暴露时间。无法确认传送状态时保留条件分支。
3. 后果模型逐行动估计资源、遇袭或交保命手段的风险、抵达时间和错过的机会。机制知识约束可行性。每项输出要带时间窗和证据质量。
4. 比较模型综合后果，输出行动排序、可并列项、决定性因素、改判条件。证据不足可暂缓排序。权衡目标、训练标签、权重和算法待案例复核后决定。
5. 先封存事前判断，再揭示玩家动作，最后核对结果。分别验证可观察后果、盲评一致性及判断覆盖率；按整场留出，冻结评价口径后再作最终验证。

## 因素登记表

|因素|要回答的问题|影响行动的方式|
|---|---|---|
|视野与信息|谁消失、最后何时何处露头、自己可能暴露在哪？|约束敌方可能位置和我方路线可预测性|
|敌方威胁|可能先到的是谁，有哪些先手、控制、爆发？|比较敌人最早接触与清线撤出时间|
|自身能力|血蓝、位移、保命手段、传送和撤退路径如何？|决定能否完成行动并脱离|
|队友协同|谁能赶到、来得及做什么、是否已交战？|影响接应、反打和支援收益|
|地图与时间|塔、地形、兵线、可达野区和目标刷新如何？|改变路径、耗时及下一步位置|
|经济发育|下一刀、下一组野、关键装备节点各值多少？|比较多留几秒与立即换区的增量收益|
|团队目标|当前要守塔、推进、控盾、接战还是等强势期？|比较个人收益与到场能改变的团队结果|

允许同一行动有多个理由。无法归入表内时，记录原话、片段及会改变哪一对行动的排序，再决定扩展因素或补数据。

## 每段复盘填写表

|阶段|必填内容|
|---|---|
|定位|比赛／补丁／英雄／秒／触发方式／可用视角|
|事前（逐个行动填写）|行动和前提；有时间戳的支持与反对证据；预计收益、风险、机会成本及时间窗；缺失信息|
|锁定判断|偏好或并列／证据不足；关键理由；哪项信息变化会改判；评审者与记录版本|
|揭示动作|实际动作、观测窗口、动作不明原因；草案意见与首次判断分别保存|
|揭示结果|实际所选动作的后果及窗口；未选行动的后果记为未知|
|修订|原判断、新解释、证据、受影响的因素或数据字段、复核状态；保留初判|

B5 现有自动评测可以检查封存的结构化动作主张，复算原开发集的已选动作误差。转野暂以带前提的条件建议表达。[评分器及结果](b5-decision-scoring.md)

## 首轮证据核对

7.41f 比赛 9080976703，斯拉克 15:12，下路。事前快照显示生命 1131/1264，魔法约 27，最近队友拉比克距离 5906。莱恩上次露头在 14:38，龙骑士在 14:40。短留需要知道下一刀还需几秒；后撤需要知道撤向何处可摆脱先手。低蓝和队友距离支持检查脱身能力，仅凭消失时长无法确定敌方先到。此处保留排序。该条为助手依据事前字段做的示范，人工初判另行登记。

先用[兵线盲评页](lane-decision-review.md)独立记录理由，后用[复核清单](lane-decision-audit.md)分析分歧。首轮产出是因素遗漏、字段缺口和反例。另补“未吃到兵即离线”“清野后换区”“可支援或不支援”的取样方案，再确认标签、数据用途、损益权衡和训练授权。

## 决策自评

在本项目中，RSI 指从一版模型的错误提出下一版改法，交给固定评分器和录像事实检验。执行顺序、唯一进度与交付条件见[计划 §7](development-plan-2026-10-30.md#b5-决策自评与迭代)。

**先封存判断。** 每个机会按比赛、英雄、场景和决策秒定位。模型只读该秒及之前己方可知的信息，先写下建议、预测窗口、证据、缺失项和改判条件。随后才揭示录像动作与结果。现有 B5 用随后六秒识别动作，第 7–20 秒观察结果。新任务如需延长窗口，应先定口径。评分器的证据要求与版本随基线保存，候选模型提出的解释供排错。

**第一道回归题。** 比赛 9021358613，风行者 15:13。玩家在此处更看重发育，认为如果打野效率更高，可以放弃推线带来的小幅地图控制。原报告记录她继续收线，结果窗内线上补刀 2 个、现金净增 139 金。历史比较的另一组只识别到后撤。提出“若计入路程和清营后，同样时长刷野赚得更多，可以转野”有明确前提；直接从后撤组现金较高推出“这一波该刷野”，应被评分器标记为无依据推荐。该例用于回归，地图控制和经济的取舍仅适用于玩家点评的这波。

| 自动报告的量 | 计算与解释 |
|---|---|
| 已选动作后果误差 | 对实际所选动作，在有预测和观测的共同样本上分别报经济、耗时等指标的平均绝对误差和样本数；另报缺测原因。现金净变化可能包含购买等收支。 |
| 有证据的建议覆盖率 | 分子为给出具体行动且通过证据核验的机会，分母为按事前规则进入评价的全部机会。条件建议、暂缓排序、动作未知和结果缺测分别计数。 |
| 无依据推荐 | 同时报次数及占全部明确推荐的比例；没有明确推荐时比例记为不可计算。检查推荐动作是否匹配历史动作、关键前提是否有事前证据、两种动作是否满足比较门槛。 |

**何时能说改进了决策。** 单项误差下降支持对该后果的估计更准。评价整体行动排序还需锁定收益目标，在两种动作都有样本且局势有可比性的比赛中评估策略价值，报告共有支持范围、按比赛计算的不确定性及未观察因素的影响。只观察到实际选择的路线，无法核实单局换条路线一定更好。开发阶段可反复分析错误，最后一次独立评分使用此前完全未参与开发的比赛。[离线策略评估](https://arxiv.org/abs/1103.4601) · [重复使用留出数据的影响](https://pubmed.ncbi.nlm.nih.gov/26250683/)
