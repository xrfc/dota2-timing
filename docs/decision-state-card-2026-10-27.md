## 3. 血蓝核验结论与未解决项

getter代码表明`get_float32`返回已解码标量，不做游戏单位换算。现场HP/maxHP及mana/maxMana与旧raw逐值一致，排除本次显示层单位转换或拼错该状态行；这只是来源一致性。

两例魔法原值仍分别约70.8751/70.8751、67.8751/67.8751。现场send-table元数据显示mana/maxMana为float32、20bit、high_value=8192。**元数据存在和数值复现不等于游戏单位已独立认证**，不能因看起来偏小就乘8或另一系数。未改变解析器、未修正旧数据，不把它接入耗蓝/可施放判断。

仍需最小语义证据核查标量解码、实际资源属性与消耗/恢复机制；本项目禁止自动打开用户Dota2客户端。本轮不把尚未完成的独立语义验证写成“已修复mana”。

```bash
  --plan reports/decision-live-probe-2026-10-27-v2/plan.json \
  --match 9056008987 --output reports/decision-probe-new/9056008987

  --output reports/decision-state-cards-new

# 查看本轮最终状态卡，仍使用8769，不再增加端口
PYTHONPATH=src .venv/bin/python scripts/decision_review.py \
  --output reports/decision-state-cards-2026-10-27-v1 --serve --port 8769
```

计划绑定执行源码和兼容解析器字节。后续实现变更须生成独立新计划，不能修改旧计划或绕过哈希。探针只读取本地已冻结录像；生成器不自动恢复网络/采集/重训练。

Windows PowerShell先设置`$env:PYTHONPATH="src"`，以`.\.venv\Scripts\python.exe`替换解释器，脚本和参数相同。服务地址`http://127.0.0.1:8769`指服务所在机器，跨设备沿用既有转发。原五例8768保留，当前8769服务按新包重启；不涉及Gateway。
