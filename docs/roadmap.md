## 产品路径与研究边界（2026-10-27定义，执行粒度见顶部更新）

用户已确认的结果：**根据位置和装备复盘，判断什么时候应该注意地图、什么时候应该保守、什么时候可以激进走位。** 回放器、断线解释和数据审计只是证据工具；不能以工具完成替代决策建议交付。静态出装实验保留为旁线，不再是近期产品的前置主任务。

### 交付形态与判断边界

围绕指定比赛、目标英雄、观察阵营和决策tick输出复盘卡：**时间点 → 当时可知信号 → 注意地图的对象/区域 → 走位倾向与具体动作 → 理由/反证 → 不确定性与证据引用**。保守可表现为后撤、换安全路线或等待；激进须说明可争取的目标和停止追击/撤退条件。证据不足输出未知/暂不建议，不强迫二选一。

“注意地图”是注意力提示，与保守/激进不是互斥的三个类别；同一时点可以既应看地图又可条件性前压。建议不是“玩家实际看了地图”：现有录像没有眼动或注意力真值。

建议只消费不晚于决策tick、该阵营可知的位置/最后可见信息和装备证据。己方状态也需验证字段时序；敌人隐藏位置、隐藏装备与未认证全知事件只能放独立的事后解释区，不进入建议输入。购买、持有、交付、背包、可用装备、冷却/充能分别核验；买到装备不自动表示已经形成战力窗口。缺少血蓝、技能、兵线或目标信息时降级，不假装仅凭距离和总价值足以判断。
