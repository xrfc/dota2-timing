# 地图资料获取与地标对照（2026-10-26）

用户批准先获取公开底图、地标、野区数据及版本信息，再核对已有录像。数据包入口：[README](../data/map-reference-2026-10-26-v1/README.md)。来源、命令、协作范围、限制均见包内说明；本报告不替代此前录像语义报告。

## 实测结果

- 固定两个上游Git提交，保存23份资源（约24.9 MB），逐文件SHA256核验通过。
- 获得底图、28个Gem野区中心、建筑/树木资料，以及待验证的327×327高度数组、47,323条阻塞网格。
- 原三场每场38个地标与公开资源对照：两座泉水推导相同平移16384/轴，其余36个地标作为对照，所有残差≤1世界单位，最大约0.44。
- 这是针对所核对静态地标的坐标平移证据，不认证官方补丁、全部地形或底图像素位置。此前“减16384未经验证”的状态由本局部证据补充，而非抹去历史记录。
- 新增10场尚无本轮同等地标核验；地图不作为13场通用真值。

## 使用建议

优先以本包作为只读参考；后续先补新增10场地标对照及底图像素校准，之后才考虑区域标签。野区区域半径属于上游分析默认值，不是用户决定。高度/通行资料只作待验证来源；不能直接生成最短路径或完整地图视野。

没有需要用户立即判断的游戏案例。尚无页面、训练、客户端操作、依赖更新、提交或推送。专项验证为资源哈希、JSON结构/计数、地标残差与唯一配对核查，不宣称全库测试或视觉验收通过。
