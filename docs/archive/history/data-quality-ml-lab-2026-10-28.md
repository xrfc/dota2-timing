## 3. 动手：未知不等于0

仓库根目录启动`.venv/bin/python`；Windows中文IDE在“运行/调试配置”选择项目现有`.venv`解释器。输入以下**纯合成教学例子**，不读取比赛、不训练模型：

```python
import math


def encode_observation(value):
    if value is None:
        return [0.0, 0.0]  # 教学填充值、是否观察到
    if type(value) not in (int, float) or not math.isfinite(value):
        raise ValueError("不是可靠的有限数字")
    return [float(value), 1.0]


print("已知CD为0：", encode_observation(0))
print("CD未知：", encode_observation(None))
```

预期分别是`[0.0, 1.0]`和`[0.0, 0.0]`。填充值都为0，但第二列让模型区分两种情况。这只是教学编码选择；正式任务需评估缺失机制、填补方式与模型适用性。知道读数但语义未验证，也不能直接设为“可靠已知”；来源质量是另一道门。

你动手修改：把输入`0`改成`30.7`，解释两列分别代表什么；再尝试`float("nan")`，确认代码拒绝而不是悄悄变为0。

**一句话：mask表达是否已知，不能让未知伪装成一个真实读数。**

## 4. 动手：概率误差不是动作标签

```python
y = [1, 0, 1, 0]  # 合成标签，不来自决策案例
p = [0.9, 0.1, 0.6, 0.4]
baseline = [0.5, 0.5, 0.5, 0.5]


def brier(labels, probabilities):
    return sum((a - b) ** 2 for a, b in zip(labels, probabilities, strict=True)) / len(labels)


print(round(brier(y, p), 6))  # 0.085
print(round(brier(y, baseline), 6))  # 0.25
```

你动手修改：把第一项预测从0.9改成0.1，再算一次。预期Brier变成0.285，已经差于0.5基线。解释：在真实标签为1时，自信地预测0.1比预测0.5惩罚更大。

这些数字说明概率误差的计算，不证明新决策模型有效；不能因知道案例后续结果就把“实际成功”当正确动作标签。

**一句话：模型要与基线在独立数据上比较，不能只看它说得是否自信。**
