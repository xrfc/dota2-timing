## 4. 够不够用（助手的判断，2026-11-16）

- **路线B**：够。第六轮规则只用了314场就有1381个片段、412次被抓死；全量大约是它的5倍。瓶颈是标签质量，不是数量。
- **路线A**：所有1号位英雄一起训练、英雄作为特征，够用；按英雄单独建模只有约10个英雄有100局以上，冷门英雄不够。
- 判断加数据有没有用，用学习曲线：用25%、50%、100%的数据训练，看验证指标是否还在涨。要补的话按英雄定向补（`collect_demos.py --hero`），联网采集每次要用户授权。

## 5. 偏差和局限

- 高分段为主（超凡入圣以上，另有约一成万古流芳），一周、一个补丁，不代表其他分段和版本。
- 只取15分钟以上的比赛；有人离开的47场没有排除。
- 位置只定了优势路的1号位和5号位；2、3、4号位还没有规则（U116的TODO）。“优势路”按每秒位置判断，换线、双优势路、三人线会定不出来。
- 天辉胜率54.5%，高于一半，可能和地图版本有关，也可能是抽样波动；没有处理。
