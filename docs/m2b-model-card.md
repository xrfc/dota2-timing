# M2b 模型卡：赛前针对装（产品A v2）

| 项 | 内容 |
|---|---|
| 用途 | 赛前查看“我的英雄”针对装（根据敌方阵容决定是否出的装备）在高分段的选择比例 |
| 英雄与装备 | 主宰1号位：金箍棒/斯嘉蒂之眼/碎颅锤/散夜对剑/否决坠饰/净魂之刃路线（含散魂剑）（U15、U16）；巫医、干扰者、神谕者5号位：U21九件，只显示出现率（U17） |
| 主要输出 | **基线**（U20）：主宰“出过针对装的局里第一件是哪件”的占比、整局出过比例；辅助整局出过比例。不随阵容变化，页面无阵容输入 |
| 模型（未启用） | 敌方定位/机制计数→softmax逻辑回归，C由训练集内分组5折CV选0.01；`reports/m2b-situational-2026-10-31-v1/`（JSON系数，无pickle） |
| 评估 | M1验证集240局（非独立），冻结协议`docs/m2b-design.md`：对数损失改善0.042，区间[−0.007, 0.087]，**未通过**（功效不足）；见`docs/m2b-results.md` |
| 参照统计 | `reports/m2b-situational-reference-2026-10-31-v1/`，M1训练集（主宰1458局，其中840局出过针对装；巫医163、干扰者151、神谕者84），`scripts/build_situational_reference.py`生成；与模型基线先验同一批比赛，服务启动时核对一致 |
| 数据 | M1快照：超凡+、≥30分钟、每场含主宰、2026-10-12至13、补丁7.41 |

## 不适用于

- 判断“该不该出”某件针对装：页面是高分段行为频率，不是装备好坏，也不是针对本局阵容的建议；
- “要不要出针对装”：主宰约42%对局未出任何针对装，第一件占比只在出过的局里计算；
- 传奇段或30分钟内结束的比赛；主宰对线崩盘局（已排除）；
- 辅助的针对性：清单中“固定装”（三人的微光披风、神谕者的Eul）出现率高是常规出装所致。

## 已知问题

- 阵容影响未被可靠证实；冻结模型待M4在新数据上评估一次（区间下限>0且改善≥0.01才启用）；
- 机制信号为技能文字自动匹配，未人工核对；
- 辅助样本少，多数装备出现<10局（页面标“样本少”）；
- 出现率也受局势和经济影响，不只由阵容决定。

## 使用

```bash
PYTHONPATH=src .venv/bin/python scripts/coach_app.py --port 8780
```

打开`http://127.0.0.1:8780`，选“赛前 · 针对装”。重建参照统计（写入新目录）：

```bash
PYTHONPATH=src .venv/bin/python scripts/build_situational_reference.py --snapshot reports/m1-match-table-2026-10-30-v1 --output NEWDIR
```

浏览器验收：`node scripts/acceptance/coach_app_browser.cjs NEWDIR`（步骤见计划§7交接备注；最新`reports/coach-app-acceptance-2026-10-31-v5`）。
