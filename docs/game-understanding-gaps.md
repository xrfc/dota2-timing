# 我们对游戏的理解还缺什么（2026-11-13，用户要求上网查）

用途：列出知识库和规则里还没有、或者只是想当然的游戏机制，按“对意识决策的影响”排序，供用户决定先补哪些。本页只是清单，没有改任何规则。

查法：网上搜了四组关键词（视野机制、7.41地图目标、开雾和真视、野怪和兵线时间），读了两篇7.41地图改动的文章；Liquipedia和Dota 2 Wiki的视野页面拒绝访问，没读到原文。能用我们自己的录像或地图数据核对的，都核对了，并在“依据”一栏写明。**网上的攻略站不是官方来源，标“网上说法”的条目还没有用官方补丁说明或游戏文件核实。**

## 1. 这次查出来、已经用自己的数据核对过的

| 事实 | 依据 | 我们现在的状态 |
|---|---|---|
| 昼夜各5分钟，开局是白天 | 录像里的`time_of_day`：0秒是16383，300秒是49097，600秒回到16328 | 视野模拟按这个算，之前是假设，现在证实了 |
| 肉山前15分钟一直在上坑；之后白天在上坑、夜晚在下坑 | 一场录像里肉山每秒的位置；网上说法“现在出现在上方的坑” | **缺**：地图草稿只标了两个坑，没有“现在在哪个坑”。每秒状态里有肉山位置，可以直接用 |
| 魔方所在的区域比兵线低一层 | 地图高度数据；网上说法一致；用户也这么说 | 已标成“魔方坑” |
| 蛙类野点会升级（有的最高到大野，赏金符旁边的最高到远古） | 网上说法；录像里赏金符旁的两个蛙类野点确实杀到了“远古蛙” | **缺**：我们给每个野点标了一个固定类型，蛙类野点的类型其实随时间变 |
| 塔的夜间视野不都一样：16座是1900／1100，6座是1900／800 | 地图数据里每座塔的数值 | **错**：视野模拟给所有塔都用了800 |
| 基地1800、遗迹2600、兵营900／600也给视野；观察者被占领后给800／450 | 地图数据 | **缺**：视野模拟没算这些 |

## 2. 网上说法，还没核实，但和意识决策直接有关

| 机制 | 网上说法 | 为什么重要 | 我们现在的状态 |
|---|---|---|---|
| 开雾的打破条件 | 靠近敌方英雄或塔1025以内就破；开雾期间真眼和塔的真视都看不到 | “从视野外出现”的抓人，很多是开雾；破雾的那一刻就是该反应的时刻 | 只记了“来的人起点前30秒内开过雾”，没有用“什么时候破雾、离他多远” |
| 飞行视野 | 不受树和高低地遮挡 | 一些技能、物品给飞行视野 | 视野模拟只有地面视野 |
| 高地看低地没问题，低地看不到高地 | 多个来源一致 | 已按此实现；我们自己的检验也支持（见`map-knowledge-design.md`§10） | 有 |
| 智慧神符 | 7:00第一次，之后每7分钟；两边都在时计时倒退 | 定点的资源，双方会按时间去抢，是可预期的遭遇点 | **缺**：没有任何“定时目标”的知识 |
| 莲花池 | 每3分钟一个，最多存6个 | 同上 | **缺** |
| 肉山 | 被杀后8–11分钟复活，具体时间不显示 | 肉山团是最大的可预期团战 | 每秒状态里有肉山死活，没有做成知识 |
| 痛苦魔方 | 7.41重做：越晚越硬；第一个在地图下半边 | 同上 | 只有位置 |
| 拉野、屯野的时间 | 屯野在每分钟的第52–55秒；辅助常在0:51、1:21拉野 | 对线期的兵线变化和辅助的位置由它决定 | **缺** |

## 3. 我们自己早就知道还没做的（不是这次查出来的）

| 缺口 | 影响 |
|---|---|
| 小兵位置（正在补，U153） | 视野模拟把五分之一“看得见”的判成看不见 |
| 树不在“不可走”数据里；被砍的树不知道 | 判断不了“隔着树林”；绕树林逃跑 |
| 坡道（上下高地的口子）没有标 | 高地只有那几个口能上，堵口、绕后都靠它 |
| 英雄状态位只存了原始数值，没有解码 | 不知道谁在隐身、被眩晕、被沉默 |
| 回城卷轴和其他传送：谁在什么时候传到哪 | 很多“别路来人”是传过来的；队友能不能传过来救也是决策依据 |
| 扫描（雷达） | 这是专门用来查“有没有人来抓”的工具，用没用、扫没扫到都没记录 |
| 每个英雄的机动能力（跳刀、位移技能的距离和冷却） | “他够不够得着我”“我跑不跑得掉” |
| 团战里的死亡归因 | 1号位44%的死亡在大团战里，现在完全没有归因 |
| 兵线状态（推过去了、被控住了、快到塔下了） | 决定他该不该在这里、多久会有人来 |
| 召唤物、幻象给的视野和威胁 | 每秒状态里有位置，没用 |

## 4. 没有查到或互相矛盾的

- 视野的精确规则（树怎么挡、站在高处能不能越过低处的树看过去、每种单位的视野距离）：两个维基页面都拒绝访问，没读到原文。
- 肉山开局在哪个坑：一处说上坑，一处说“夜魇坑”。我们的录像显示是上坑。
- 真眼的范围：一处说真视1000，一处说150，后者像是错的。
- 屯野时间各站说法略有出入（52–55秒）。
- 7.41之后到7.41f之间地图有没有再改：没有查到；我们的可走网格和7.41f录像对得上（`map-knowledge-design.md`§9）。

## 5. 建议的顺序（助手的建议，待用户定）

1. 视野模拟里马上能改的三项：塔的夜间视野用各自的数值；加上基地、遗迹、兵营；用上全部小兵（U153正在抽）。改完重新检验。
2. 定时目标的知识（智慧神符、莲花池、肉山、魔方、符、屯野拉野）：先用官方补丁说明或游戏文件核实时间，再做成一份知识文件。
3. 肉山当前在哪个坑、蛙类野点当前是什么类型：都能从录像里直接得到。
4. 传送、扫描、英雄状态位：要改解析器，放在B0验收之后。
