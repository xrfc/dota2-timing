# M2 设计：出装时间预测（产品A）

状态：**评估协议于2026-10-30冻结，冻结时尚未训练、尚未看任何模型结果。** 修订记录：神谕者加回以太透镜（U11），发生在训练前。 修改协议须新决策记录，并在报告中说明修改发生在看结果之前还是之后。

## 1. 任务

给定赛前阵容，预测“我的英雄”的关键装备在第N分钟前是否已做出（首次出现在purchase_log的时间 < N×60秒）。

| 项 | 设置 | 来源 |
|---|---|---|
| 英雄与位置 | 主宰1号位（排除`collapsed_carry`）；巫医、干扰者、神谕者5号位 | U9、U8 |
| 关键装备 | 见U10；神谕者加回以太透镜（U11，训练前修改）；“吹风”训练正例<10，只报频率不建模 | U10、U11 |
| 时间点N | 10、15、20、25、30分钟 | 计划M2-T1 |
| 数据 | `reports/m1-match-table-2026-10-30-v1`，训练1595场／验证398场 | M1 |
| 删失 | 数据全部≥30分钟，N≤30无删失 | M1数据卡 |

样本量（训练）：主宰1458、巫医163、干扰者151、神谕者84。验证集更小（神谕者约20），区间会很宽。

## 2. 输入（仅赛前字段，经`pre_game_view`）

- 我方4名队友hero_id、敌方5名hero_id（各自one-hot，按训练集出现的英雄建词表；未见英雄计入unknown计数）
- 我方阵营（天辉/夜魇）
- 不用：账号、段位（几乎恒定）、任何对线/赛后字段

## 3. 模型（实现选择，非用户决定）

- 基线B0：训练集中该(英雄,装备,N)的正例率。
- 模型M：每个(英雄,装备,N)一个L2逻辑回归（scikit-learn，lbfgs，C=1.0固定，max_iter=1000），只在训练集拟合，预处理只用训练集词表。
- 跳过建模：训练正例或负例<10时只用B0。
- 不做：调参搜索、特征选择、深度模型、跨英雄共享参数。
- 展示用的时间分布由各N的概率取累积最大值保证单调。

## 4. 评估协议（冻结）

- 数据：M1验证集398场，只用一次做本协议报告；结论不称“独立”（M1数据卡§5），独立评估在M4。
- 指标：每个(英雄,装备,N)的Brier与对数损失；每英雄宏平均。
- 比较：M相对B0的Brier差，比赛级bootstrap 95%区间（1000次，seed=0）。
- 展示规则：某(英雄,装备,N)只有当Brier改善区间不含0时，页面才显示模型概率；否则显示B0频率并注明“阵容对此项无可靠影响”。
- 诊断（不改变上述结论）：10分箱校准、样本量、主宰与辅助分开报告。
- 全部结果如实报告，包括不优于基线的项。

## 6. 局限（先写明）

高分段（U7）且≥30分钟比赛，出装节奏不代表传奇段或短局；每场有主宰；辅助样本少；阵容对出装时间的影响可能很弱，模型不优于基线是可能且可接受的结果。
