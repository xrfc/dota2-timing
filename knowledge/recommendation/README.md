# 版本化阵容规则知识包

当前包：[7.41f-v1](7.41f-v1/knowledge.json)，策略见 [policy.json](7.41f-v1/policy.json)。
首版只启用一号位主宰；完整使用、来源边界、扩展方法和验收状态见
[本地推荐说明](../../docs/lineup-recommendation.md)。

- `knowledge.json`：英雄身份、逐条事实/条件、装备白名单、来源 URL/字节哈希、版本关联。
- `policy.json`：英雄/位置支持范围、需求规则和启发式装备权重，非官方最佳决策事实。
- `sources/`：本轮保存的27份原始 JSON 字节；Git 禁止换行转换以保持跨平台哈希。
- 官方资料来自 `www.dota2.com/datafeed/`；身份目录复用 OpenDota 固定提交
  `bf193a550f778dec35debf4d71d05a86bebcc418`。逐文件地址均在知识包中。

详情来源本身没有明确补丁字段。本包通过官方补丁表、带7.41f标识的补丁说明和三个
改动锚点关联当前快照，不声称取得游戏 build 证明。所有核对限于资料与窄文字效果，
未做客户端或用户逐条验收；来源完整性检查不能证明人为填写的摘要/规则语义正确。
源文件与哈希同时被改动的情况也不是密码学签名能够阻止的；版本控制用于审查变化。

原始技能/装备文字权利归其原权利人，项目代码许可证不把它们重新授权为MIT。
本包不包含真实比赛或玩家信息，不作为模型训练准入记录。旧官网学习快照仍保留原状态，
不因本包存在而批量改写其 patch 或审核字段。

后续修订新建版本目录，保留旧来源与策略供复现；当前生成报告位于忽略的 `reports/`，
不提交临时下载探索脚本、缓存或报告副本。
