# Codex第3轮：U5抽查剩余组独立复核（U41）

范围：U5抽查497组中，用户未标且Codex第2轮未审的387组。其中8组因v3已隔离过时升级文字未送审，实审**379组**。由Claude通过`codex exec --sandbox read-only`调用，共13批，约38万tokens。

## 结果

Codex接受355、不确定21、排除3；Claude这379组全为接受。分歧24组，其中14组是“可被破坏”。分歧与裁定建议见[待用户裁定汇总](../../../../docs/handoff/user-rulings-2026-11-02.md)H块；24组已由U42–U45全部裁定，结果均为接受，部分附条件。

同标签355组未比较生效条件，不算用户确认，也不是全量准确率。P2、P3中未进入抽样的组本轮没有审。

## 方法与局限

- 输入不含Claude判断，运行目录为空，并要求不读其他文件。只读沙箱挡不住读盘，这一点靠指令约束，不是技术隔离。
- 输入中的用户口径见`prompt.md`。其中“召唤物须是能被选中或攻击的独立单位”是助手从U39归纳的，用户未定为通用规则；“字段只证明被动分类”很可能是14组“可被破坏”不确定的原因，同机制另有9组被接受，判断并不一致。
- 装备的`context`只带附注，主说明只出现在被抽中的证据里。刃甲、风之杖的不确定部分由此造成。
- 未运行游戏，也没有联网。
