# 词表缺口排查（U61）

把词表v5和两路线索对照：游戏提示文字里的`MODIFIER_PROPERTY_*`，以及按候选关键词扫描127位英雄的技能和当前可购买装备的英文说明。结果在`report.json`，`scan.py`可重放。

**数字只是关键词命中的线索，有误报也可能有漏，没有逐条确认。候选清单是助手凭游戏知识列的。不改词表，等用户决定。**

词表已覆盖、不算缺口：恐惧、嘲讽、催眠（强制行为）；吸血、治疗、回蓝、状态抗性、减速抗性、闪避、致盲等。
