# 其他机制对照游戏文件（U48）

用游戏文件的结构化字段排查机制证据。**只列疑点，没有改任何判断。** 字段名命中不等于确实有该机制，候选须逐个确认。

## 1. Valve接口字段：没有发现问题

登记表734个技能中733个能在游戏文件找到。免疫、驱散、伤害类型、被动、单位目标5个字段在这733个技能上全部一致。没找到的1个不计入。

## 2. 持续施法：40组，36组一致

- 接受但字段没有`CHANNELLED`（4组）：陈·上帝之手（A杖升级才变持续施法，字段看不出）、孽主·恶魔之扉（文字说的是英雄使用传送门）、米波·忽悠（文字写channeling）、齐天大圣·丛林之舞（文字说的是乾坤之跃）。
- 有字段但没有接受组（2个）：暗影萨满·枷锁、育母蜘蛛·蛛纱陷阱（A杖相关隐藏技能）。

## 3. 单体指向：161组，160组一致

- 排除但有字段（1组）：齐天大圣·丛林之舞，它主要指向树。
- 有字段但没有接受组51个：36个只能选友方，符合U31定义；13个阵营字段是CUSTOM或ENEMY，2个无阵营字段。CUSTOM中幻影突袭、移形换位、衰老、闪烁突袭等可能漏记，见`strict-field-checks.json`。

## 4. `AbilityValues`字段名候选：线索，不是结论

已去掉有复核组或装备属性事实的情况。没有任何记录且基础值非零的共173个（英雄57、装备116），另有英雄56个只在A杖、魔晶或天赋下非零。

- `mana_gain`的52个基本是装备回蓝属性，`illusions`的19个多是幻象伤害系数，噪音大。其余约102个值得复核。
- 已看到的原因：文字根本没写（如裂魂人·暗影冲刺的`stun_duration`），或信息只在装备技能标题和属性（如代达罗斯`crit_chance`，说明文字没有“暴击”一词）。
- **用户裁定后（U51）：只有字段名、没有标签和文字支持的候选，用户答的基本都是没有。字段名不能单独当证据。**
- 已知误报类型：字段名含关键词但意义不同（如法术反制`does_reflect`是反射法术，不是反伤）。部分装备是中立物品或未进入当前商店，范围待定。
- 完整清单：`keyword-triage.json`。

## 5. 装备版本

dotaconstants与`items.txt`比较售价：相同486、不同4、不可比较10、缺失1。死灵书3级售价和配方不同，但`items.txt`把死灵书标为`IsObsolete=1`、不可购买。**所以这不能证明社区快照过时**（2026-11-03更正此前说法）；它说明快照里还有已退出的装备。

## 6. 无法用字段核对的机制

弱驱散、强驱散、施加破坏、强制行为、位移、隐身等没有可靠字段，只能靠文字和用户知识。

