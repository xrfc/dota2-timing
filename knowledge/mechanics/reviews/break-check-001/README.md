## 证据强度

- 接受的37组，Claude都接受，有Codex结果的36组Codex也接受（见各轮记录），但游戏文件没有标记。**两个AI一致不能替代来源核对。** 它们当时都用了U33“先天除魔法盾外都可破坏”的口径。
- 支持标记可信的证据：H1的14组全部有标记；美杜莎魔法盾、小小长大、米波分则能成都没有标记，符合用户此前说的例外。U40排除的9组中8组没有标记。
- **“无标记”不等于已证实不可破坏。** 标记含义来自用户“游戏里写了”和7.37更新的二手摘要，未读到Valve对字段的说明，也没有在游戏里实测。

## 版本与来源

- 快照：`knowledge/game-files/snapshots/2026-11-02/`，第三方镜像SteamDatabase/GameTracking-Dota2固定提交（见`manifest.json`），仓库未声明许可证，文件内容属于游戏文件。
- 版本核对：登记表734个技能中，706个可比较的英文说明去掉标记和空白后与游戏文件完全一致，28个不可比较。这说明文字版本相符，不等于认证了补丁号，`patch_verified`仍为false。
- 只核对英雄技能：180组都不是装备，`items.txt`也没有这个字段。
