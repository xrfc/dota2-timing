# 自身位移分类（U96）

用户定跳跃和冲刺都算无视地形，所以把v13里接受的全部81个自身位移对象分类。

- Codex：`gpt-6.1-sol`，`reasoning effort: high`，临时账号，4批，约9万tokens。盲审，只看说明文字。
- 结果：跳跃冲刺49个（含兼有其他方式的7个）、传送28个（含兼有其他方式的3个）、其他2个（震荡手雷、一箭穿心，都是把自己击退），还有星破天惊和风之杖这类自由移动。2个不确定。
- 天光现世Codex分为跳跃冲刺，用户定为类似传送，以用户为准。
- `make_rulings.py`把U95–U98写成`../terrain-rulings-001.jsonl`。地雷滚滚和天光现世不算（前者说明写碰到地形会停，助手判断；后者用户定）。

局限：分类是Codex读文字做的，没有运行游戏。说明没有写能否越过地形，这条是用户定的一般规则。
