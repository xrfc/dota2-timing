# 新增“加速”机制：候选审查（U120）

用户决定（U120）：新增“加速”机制，记录提升自身或友方移动速度的效果（给队友加速也算）；“可被弱驱散的保命效果”只算主要作用是跑的加速，由用户逐个复核。

- `candidates.json`：官方说明或数值字段里出现提升移速的技能和装备，共190个（关键词粗筛，含很多只让敌人减速的误命中）。
- `build_packet.py`：从`full-audit-001/objects.json`取说明原文，25个一批写进`batches/`。
- Codex独立判断（`rules.md`、`schema.json`、`run_batch.sh`，模型`gpt-6.1-sol`，推理强度high，只读、空目录、不存会话）：是否提升移速、给谁、是否只在升级后有、主要用途是不是跑。结果在`results/`。
- 之后Claude看依据，用户复核“主要作用是跑”的名单，再出词表v14、新事实版本和特性映射v6。
- 第二轮候选：第一轮关键词漏了59个（如黑暗贤者·奔腾、狼人·变身、祈求者·幽灵漫步、速度之靴），改用更宽的关键词（说明、备注、升级文字、数值名里出现“移动速度/移速/movement speed”）补上，见`candidates-round2.json`，批次009起。

## 结果（2026-11-07）

- 两轮共249个候选，Codex判断116个提升移速（自身、友方或两者），12个不确定，其余不提升（多是只减速敌人）。Claude逐条看过提升移速和不确定的依据，没有发现要推翻的判断；这些行按以前的做法记为`two_ai`（Codex提出、Claude看过依据，不是两边盲审）。
- 和“可被弱驱散的保命效果”有关的只有能被弱驱散（`dispellable=2`）的26个技能：Codex建议16个“主要用来跑”，10个“顺带加速”。这份名单交给用户逐个定（U120）。
- 不确定的12个先不记加速，等以后有证据再说（多是只有数值名、说明没写，或支配头盔这类设定被控单位移速的）。
